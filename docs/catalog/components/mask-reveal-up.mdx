## Variables

Every one of these has a default, so the piece works untouched. Set the ones you
want to change on the element:

| Variable | Default | Accepts | What it does |
| --- | --- | --- | --- |
| `origin` | `left` | `left`, `right`, `straight` | Which side the lines swing in from before they settle. |
| `distance` | `standard` | `close`, `standard`, `far` | Scales the travel offsets, so the lines cover a shorter or longer run in the same time. |
| `line_gap` | `standard` | `tight`, `standard`, `loose` | Vertical space between the stacked lines. |
| `tone` | `ink` | `ink`, `paper`, `accent` | Line colour: ink for light frames, paper for dark ones, accent rides --brand. |

Set them with `data-variable-values` on the element that mounts it. These are the
defaults, so this behaves exactly like the preview above until you change one:

```html wrap
<div
  data-composition-id="mask-reveal-up"
  data-composition-src="compositions/components/mask-reveal-up.html"
  data-variable-values='{"origin":"left","distance":"standard","line_gap":"standard","tone":"ink"}'
></div>
```

<!--
  Mask Reveal Up - remocn typography primitive for HyperFrames.

  Paste the markup, CSS and script into a composition. Drive the timeline
  integration from a paused GSAP timeline so renders remain deterministic.

  Variables. The script reads each one, falls back to the declared default on
  anything missing or unrecognised, and writes the result as a custom property
  the CSS consumes. The timeline recipe below is untouched by them: it keeps
  driving one horizontal offset, one vertical offset and one blur, and these
  decide what that pair of offsets means on screen.

    - origin (left | right | straight, default left): which side the lines
      swing in from. left is the original diagonal, right mirrors it, straight
      drops the horizontal part so the lines rise vertically.
    - distance (close | standard | far, default standard): scales both offsets.
      close covers half the run, far nearly double, in the same time.
    - line_gap (tight | standard | loose, default standard): vertical space
      between the two lines, 4px, 10px or 20px.
    - tone (ink | paper | accent, default ink): line colour. ink is near-black
      for light frames, paper near-white for dark ones, accent rides --brand.

  On every default the result is identical to the original: lines arrive from
  36px left and 18px below through a 6px blur, near-black, 10px apart.
-->

<script>
  (function () {
    "use strict";

    var vars =
      window.__hyperframes && window.__hyperframes.getVariables
        ? window.__hyperframes.getVariables()
        : {};

    // Unrecognised overrides return to their declared defaults.
    var origins = { left: 1, right: -1, straight: 0 };
    var reaches = { close: 0.5, standard: 1, far: 1.85 };
    var gaps = { tight: "4px", standard: "10px", loose: "20px" };
    var tones = {
      ink: "#18181b",
      paper: "#fafafa",
      accent: "var(--brand, #34d399)",
    };

    function pick(table, value, fallback) {
      return Object.prototype.hasOwnProperty.call(table, value) ? value : fallback;
    }

    var originX = origins[pick(origins, vars.origin, "left")];
    var reach = reaches[pick(reaches, vars.distance, "standard")];
    var gap = gaps[pick(gaps, vars.line_gap, "standard")];
    var tone = tones[pick(tones, vars.tone, "ink")];

    var roots = document.querySelectorAll(".hf-remocn-mask-reveal-up");
    for (var i = 0; i < roots.length; i += 1) {
      roots[i].style.setProperty("--hf-line-reach-x", String(originX * reach));
      roots[i].style.setProperty("--hf-line-reach-y", String(reach));
      roots[i].style.setProperty("--hf-line-gap", gap);
      roots[i].style.setProperty("--hf-line-color", tone);
    }
  })();
</script>
