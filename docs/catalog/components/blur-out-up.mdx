## Variables

Every one of these has a default, so the piece works untouched. Set the ones you
want to change on the element:

| Variable | Default | Accepts | What it does |
| --- | --- | --- | --- |
| `direction` | `up` | `up`, `down`, `left`, `right` | Where the offset the timeline drives points. |
| `distance` | `standard` | `close`, `standard`, `far` | Scales the travel offset, so the words cover a shorter or longer run in the same time. |
| `blur` | `standard` | `soft`, `standard`, `heavy` | Scales the blur radius the timeline drives, from a light haze to a full smear. |
| `tone` | `ink` | `ink`, `paper`, `accent` | Word colour: ink for light frames, paper for dark ones, accent rides --brand. |

Set them with `data-variable-values` on the element that mounts it. These are the
defaults, so this behaves exactly like the preview above until you change one:

```html wrap
<div
  data-composition-id="blur-out-up"
  data-composition-src="compositions/components/blur-out-up.html"
  data-variable-values='{"direction":"up","distance":"standard","blur":"standard","tone":"ink"}'
></div>
```

  Paste the markup, CSS and script into a composition. Drive the timeline
  integration from a paused GSAP timeline so renders remain deterministic.

  Variables. The script reads each one, falls back to the declared default on
  anything missing or unrecognised, and writes the result as a custom property

  keeps driving one offset and one blur, and these decide what that offset and
  that blur mean on screen.

    - direction (up | down | left | right, default up): where the offset
      points. up rises into place, down drops in, left and right slide in
      along the baseline.
    - distance (close | standard | far, default standard): scales the offset.
      close covers half the run, far nearly double, in the same time.
    - blur (soft | standard | heavy, default standard): scales the blur radius,
      from a light haze to a full smear.
    - tone (ink | paper | accent, default ink): word colour. ink is near-black
      for light frames, paper near-white for dark ones, accent rides --brand.

  On every default the result is identical to the original: words rise 22px
  through a 5px blur in near-black.

  (function () {
    "use strict";

    var vars =
      window.__hyperframes && window.__hyperframes.getVariables
        ? window.__hyperframes.getVariables()
        : {};

    // Unrecognised overrides return to their declared defaults.
    var axes = {
      up: { x: 0, y: 1 },
      down: { x: 0, y: -1 },
      left: { x: -1, y: 0 },
      right: { x: 1, y: 0 },

    var reaches = { close: 0.5, standard: 1, far: 1.85 };
    var blurScales = { soft: 0.45, standard: 1, heavy: 2.2 };

      ink: "#18181b",
      paper: "#fafafa",
      accent: "var(--brand, #34d399)",
    };

    function pick(table, value, fallback) {
      return Object.prototype.hasOwnProperty.call(table, value) ? value : fallback;
    }

    var axis = axes[pick(axes, vars.direction, "up")];
    var reach = reaches[pick(reaches, vars.distance, "standard")];
    var blurScale = blurScales[pick(blurScales, vars.blur, "standard")];
    var tone = tones[pick(tones, vars.tone, "ink")];

    var roots = document.querySelectorAll(".hf-remocn-blur-out-up");

      roots[i].style.setProperty("--hf-word-axis-y", String(axis.y * reach));
      roots[i].style.setProperty("--hf-word-blur-scale", String(blurScale));
      roots[i].style.setProperty("--hf-word-color", tone);
    }
  })();
</script>
