## Variables

Every one of these has a default, so the piece works untouched. Set the ones you
want to change on the element:

| Variable | Default | Accepts | What it does |
| --- | --- | --- | --- |
| `accent` | `blue` | `blue`, `violet`, `green` | Colour family of the incoming plate. Green rides --brand and --accent. |
| `format` | `wide` | `wide`, `square`, `portrait` | Aspect of the tile the transition plays inside. |
| `corner` | `soft` | `soft`, `sharp`, `round` | Corner radius of the tile. |
| `chroma` | `standard` | `off`, `subtle`, `standard` | Strength of the red and cyan fringe that stutters over the wipe. Off removes it. |

Set them with `data-variable-values` on the element that mounts it. These are the
defaults, so this behaves exactly like the preview above until you change one:

```html wrap
<div
  data-composition-id="image-expand-to-fullscreen"
  data-composition-src="compositions/components/image-expand-to-fullscreen.html"
  data-variable-values='{"accent":"blue","format":"wide","corner":"soft","chroma":"standard"}'
></div>
```

      return Object.prototype.hasOwnProperty.call(table, value) ? value : fallback;
    }

    var accents = {
      blue: { a: "#2563eb", b: "#7c3aed" },
      violet: { a: "#7c3aed", b: "#db2777" },
