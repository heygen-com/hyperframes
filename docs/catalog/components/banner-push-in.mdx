<!--
  Banner Push-In - notification banner arrival primitive.

  Paste the markup, CSS and script into a composition. Use the timeline
  integration note at the bottom as the starting point for deterministic GSAP
  animation.

  One banner is one arrival. Duplicate .hf-bpi-banner per notification and give
  each its own id; they all share the same entry recipe. When a new banner
  lands, every banner already on screen slides up one pitch in lockstep with
  it - that slide is the second line of the timeline recipe.

  Variables. The script reads each one, falls back to the declared default on
  anything missing or unrecognised, and writes the result as a custom property
  the CSS below consumes. The timeline recipe is untouched by them.

    - width (480 to 960, default 810, in px): banner width. Type and icon
      scale from it, so the banner keeps its proportions at any width.
    - rise (8 to 60, default 22, in px): how far a banner rises into place as
      it fades in. The reference travel is 22px.
    - pitch (140 to 320, default 214, in px): the distance the stack slides up
      when a new banner arrives. Keep it at banner height + gap.
    - tone (glass | solid, default glass): glass is a warm translucent card
      for footage or bright grounds; solid is the raised surface token for
      flat compositions.

  On every default the result matches the measured reference: an 810px glass
  banner rising 22px onto a 214px pitch.
-->

## Paste it into your composition

Open `compositions/components/banner-push-in.html` and copy what is inside into your own composition.

A component has no size or duration of its own. It takes both from the composition
you paste it into.

## Variables

Every one of these has a default, so the piece works untouched. Set the ones you
want to change on the element:

| Variable | Default | Accepts | What it does |
| --- | --- | --- | --- |
| `width` | `810` | 480px to 960px, step 10px | Banner width in pixels; icon and type scale with it. |
| `rise` | `22` | 8px to 60px, step 1px | How far a banner rises into place while it fades in. |
| `pitch` | `214` | 140px to 320px, step 2px | How far the stack slides up when a new banner arrives. |
| `tone` | `glass` | `glass`, `solid` | Glass for footage and bright grounds, solid for flat compositions. |

Set them with `data-variable-values` on the element that mounts it. These are the
defaults, so this behaves exactly like the preview above until you change one:

```html wrap
<div
  data-composition-id="banner-push-in"
  data-composition-src="compositions/components/banner-push-in.html"
  data-variable-values='{"width":810,"rise":22,"pitch":214,"tone":"glass"}'
></div>
```
