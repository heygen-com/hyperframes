## Variables

Every one of these has a default, so the piece works untouched. Set the ones you
want to change on the element:

| Variable | Default | Accepts | What it does |
| --- | --- | --- | --- |
| `theme` | `dark` | `dark`, `light` | Operator Black token theme the card renders in. |
| `accent` | `green` | `green`, `blue`, `amber`, `violet` | Accent token family used for the status text and focus rings. |
| `density` | `comfortable` | `comfortable`, `compact` | Padding and row spacing inside the card. |

Set them with `data-variable-values` on the element that mounts it. These are the
defaults, so this behaves exactly like the preview above until you change one:

```html wrap
<div
  data-composition-id="card"
  data-composition-src="compositions/components/card.html"
  data-variable-values='{"theme":"dark","accent":"green","density":"comfortable"}'
></div>
```

  Paste the markup, CSS and script into a composition. Animate the CSS

  Variables. The script reads each one, falls back to the declared default on
  anything missing or unrecognised, and applies it to the card root. The
  timeline recipe at the bottom is untouched by them: it keeps driving the
  same reveal, and these decide what that reveal is dressed in.

    - accent (green | blue | amber | violet, default green): the data token

      in both themes, so the default reads correctly on either.
    - density (comfortable | compact, default comfortable): padding and row
      spacing inside the card.
