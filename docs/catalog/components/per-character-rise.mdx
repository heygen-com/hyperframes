## Variables

Every one of these has a default, so the piece works untouched. Set the ones you
want to change on the element:

| Variable | Default | Accepts | What it does |
| --- | --- | --- | --- |
| `origin` | `above` | `above`, `below` | Which side of the line the letters travel from. above is the shipped motion, below mirrors it. |
| `distance` | `standard` | `close`, `standard`, `far` | Scales the travel offset, so the letters cover a shorter or longer run in the same time. |
| `size` | `74` | 32px to 160px, step 1px | Type size, which also sets how tall the clipping window is. |
| `tone` | `ink` | `ink`, `paper`, `accent` | Letter colour: ink for light frames, paper for dark ones, accent rides --brand. |

Set them with `data-variable-values` on the element that mounts it. These are the
defaults, so this behaves exactly like the preview above until you change one:

```html wrap
<div
  data-composition-id="per-character-rise"
  data-composition-src="compositions/components/per-character-rise.html"
  data-variable-values='{"origin":"above","distance":"standard","size":74,"tone":"ink"}'
></div>
```

<!--
  Per Character Rise - remocn typography primitive for HyperFrames.

  Paste the markup, CSS and script into a composition. Drive the timeline
  integration from a paused GSAP timeline so renders remain deterministic.

  Variables. The script reads each one, falls back to the declared default on
  anything missing or unrecognised, and writes the result as a custom property
  the CSS below consumes. The timeline recipe at the end is untouched by them: it
  keeps driving one offset, and these decide what that offset means on screen.

    - origin (above | below, default above): which side of the line the
      letters travel from. above is the shipped motion, below mirrors it so
      the letters climb into place instead.
    - distance (close | standard | far, default standard): scales the offset.
      close covers half the run, far nearly double, in the same time.
    - size (number, 32 to 160, default 74): type size in px, which also sets
      how tall the clipping window is.
    - tone (ink | paper | accent, default ink): letter colour. ink is
      near-black for light frames, paper near-white for dark ones, accent
      rides --brand.

  On every default the result is identical to the original: 74px near-black
  letters travelling 42px into the line.
-->

<div
  class="hf-remocn-per-character-rise"
  data-composition-variables='[
    { "id": "origin", "type": "enum", "role": "motion", "label": "Origin", "description": "Which side of the line the letters travel from. above is the shipped motion, below mirrors it.", "default": "above", "options": [{ "value": "above", "label": "Above" }, { "value": "below", "label": "Below" }] },

>

<style>
  .hf-remocn-per-character-rise {
    color: var(--hf-char-color, #18181b);
    font-family: Inter, system-ui, sans-serif;
    font-weight: 900;
    letter-spacing: -0.04em;
  }
  .hf-remocn-per-character-rise {
    display: inline-flex;

    font-size: var(--hf-char-size, 74px);
    line-height: 0.9;
    overflow: hidden;
  }
  .hf-remocn-per-character-rise span {
    display: inline-block;
    transform: translateY(calc(var(--hf-char-y, 0px) * var(--hf-char-reach, 1)));
    will-change: transform, opacity;
  }
</style>

<script>
  (function () {
    "use strict";

    var vars =
      window.__hyperframes && window.__hyperframes.getVariables
        ? window.__hyperframes.getVariables()
        : {};

    // Unrecognised overrides return to their declared defaults.
    var origins = { above: 1, below: -1 };
    var reaches = { close: 0.5, standard: 1, far: 1.85 };
    var tones = {
      ink: "#18181b",
      paper: "#fafafa",
      accent: "var(--brand, #34d399)",
    };

    function pick(table, value, fallback) {
      return Object.prototype.hasOwnProperty.call(table, value) ? value : fallback;
    }

    var origin = origins[pick(origins, vars.origin, "above")];
    var reach = reaches[pick(reaches, vars.distance, "standard")];
    var tone = tones[pick(tones, vars.tone, "ink")];

    var size = Number(vars.size);
    if (!isFinite(size) || size < 32 || size > 160) {
      size = 74;
    }

    var roots = document.querySelectorAll(".hf-remocn-per-character-rise");
    for (var i = 0; i < roots.length; i += 1) {
      roots[i].style.setProperty("--hf-char-reach", String(origin * reach));
      roots[i].style.setProperty("--hf-char-size", size + "px");
      roots[i].style.setProperty("--hf-char-color", tone);
    }
  })();
</script>
