## Variables

Every one of these has a default, so the piece works untouched. Set the ones you
want to change on the element:

| Variable | Default | Accepts | What it does |
| --- | --- | --- | --- |
| `direction` | `up` | `up`, `down`, `left`, `right` | Which way the words travel in: up rises from below the baseline, down settles from above, left and right carry the same offset sideways instead. |
| `distance` | `standard` | `close`, `standard`, `far` | Scales the travel offset, so the words cover a shorter or longer run in the same time. |
| `pop` | `standard` | `subtle`, `standard`, `deep` | How far the words shrink before they settle, scaling the dip away from full size while the resting frame stays at full size. |
| `tone` | `ink` | `ink`, `paper`, `accent` | Word colour: ink for light frames, paper for dark ones, accent rides --brand. |

Set them with `data-variable-values` on the element that mounts it. These are the
defaults, so this behaves exactly like the preview above until you change one:

```html wrap
<div
  data-composition-id="short-slide-right"
  data-composition-src="compositions/components/short-slide-right.html"
  data-variable-values='{"direction":"up","distance":"standard","pop":"standard","tone":"ink"}'
></div>
```

  Short Slide Right - remocn typography primitive for HyperFrames.

  Paste the markup, CSS and script into a composition. Drive the timeline
  integration from a paused GSAP timeline so renders remain deterministic.

  Variables. The script reads each one, falls back to the declared default on
  anything missing or unrecognised, and writes the result as a custom property
  the CSS above consumes. The timeline recipe below is untouched by them: it
  keeps driving one offset, one scale and one blur, and these decide what that
  offset and that scale mean on screen.

    - direction (up | down | left | right, default up): which way the words
      travel in. up rises from below the baseline, down settles from above,
      left and right carry the same offset sideways along the baseline instead.
    - distance (close | standard | far, default standard): scales the travel
      offset. close covers half the run, far nearly double, in the same time.
    - pop (subtle | standard | deep, default standard): scales how far the
      words shrink before they settle. subtle barely dips, deep drops to about
      a fifth under full size. The resting frame is always full size, so this
      only changes the middle of the move.
    - tone (ink | paper | accent, default ink): word colour. ink is near-black
      for light frames, paper near-white for dark ones, accent rides --brand.

  On every default the result is identical to the original: words rise 22px
  from 0.92 scale through a 5px blur in near-black.

<script>
  (function () {
    "use strict";

    var vars =
      window.__hyperframes && window.__hyperframes.getVariables
        ? window.__hyperframes.getVariables()
        : {};

    // Unrecognised overrides return to their declared defaults.
    function pick(table, value, fallback) {
      return Object.prototype.hasOwnProperty.call(table, value) ? value : fallback;
    }

    var axes = {
      up: { x: 0, y: 1 },
      down: { x: 0, y: -1 },
      left: { x: -1, y: 0 },
      right: { x: 1, y: 0 },
    };
    var reaches = { close: 0.5, standard: 1, far: 1.85 };
    var pops = { subtle: 0.4, standard: 1, deep: 2.2 };
    var tones = {
      ink: "#18181b",
      paper: "#fafafa",
      accent: "var(--brand, #34d399)",
    };

    var axis = axes[pick(axes, vars.direction, "up")];
    var reach = reaches[pick(reaches, vars.distance, "standard")];
    var pop = pops[pick(pops, vars.pop, "standard")];
    var tone = tones[pick(tones, vars.tone, "ink")];

    var roots = document.querySelectorAll(".hf-remocn-short-slide-right");
    for (var i = 0; i < roots.length; i += 1) {
      roots[i].style.setProperty("--hf-word-axis-x", String(axis.x * reach));
      roots[i].style.setProperty("--hf-word-axis-y", String(axis.y * reach));
      roots[i].style.setProperty("--hf-word-pop", String(pop));
      roots[i].style.setProperty("--hf-word-color", tone);
    }
  })();
</script>
