## Variables

Every one of these has a default, so the piece works untouched. Set the ones you
want to change on the element:

| Variable | Default | Accepts | What it does |
| --- | --- | --- | --- |
| `fill` | `50` | 0% to 100%, step 1% | How much of the rail is filled, as a percentage of the list height. Values outside the range are clamped to it. |
| `accent` | `theme` | `theme`, `blue`, `violet`, `amber` | Colour family for the filled rail and the step markers. Theme leaves the inherited accent token alone. |
| `density` | `standard` | `compact`, `standard`, `roomy` | Row height, with the rail insets kept centred on the first and last markers. |
| `entrance` | `standard` | `subtle`, `standard`, `bold` | Scales the sideways offset the timeline drives, so rows slide in from closer or further out in the same time. |

Set them with `data-variable-values` on the element that mounts it. These are the
defaults, so this behaves exactly like the preview above until you change one:

```html wrap
<div
  data-composition-id="progress-steps"
  data-composition-src="compositions/components/progress-steps.html"
  data-variable-values='{"fill":50,"accent":"theme","density":"standard","entrance":"standard"}'
></div>
```
