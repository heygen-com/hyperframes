  Line Reveal List - checklist paragraph-rhythm primitive.

  Paste the markup, CSS and script into a composition. Use the timeline
  integration note at the bottom as the starting point for deterministic GSAP
  animation.

  Two measured behaviours, from reference footage of a note being written:

  1. The cadence. Lines do not land evenly - the measured beats between
     paragraphs are 2.20s, 2.03s, 2.97s, 3.10s, 3.33s, 3.63s: the writer
     slows down as the thought gets heavier. Cycle the CADENCE table for any
     line count.
  2. The settle. When the page makes room, it does not glide linearly - the
     EASE table is the measured scroll curve (fast launch, long soft
     settle over ~0.55s). Play it as stepped sets, or approximate with
     expo.out if steps feel heavy.

  Variables. The script reads each one, falls back to the declared default on
  anything missing or unrecognised, and writes the result as a custom property
  the CSS below consumes.

    - size (24 to 96, default 52, in px): type size of the lines.
    - marker (check | bullet | none, default check): what leads each line.

## Install

<InstallCommand command="npx hyperframes add line-reveal-list" item="line-reveal-list" />

That writes one file: `compositions/components/line-reveal-list.html`.

## Paste it into your composition

Open `compositions/components/line-reveal-list.html` and copy what is inside into your own composition.
The file opens with a comment header that walks you through it.

A component has no size or duration of its own. It takes both from the composition
you paste it into.

## Variables

Every one of these has a default, so the piece works untouched. Set the ones you
want to change on the element:

| Variable | Default | Accepts | What it does |
| --- | --- | --- | --- |
| `size` | `52` | 24px to 96px, step 2px | Type size of the list lines. |
| `marker` | `check` | `check`, `bullet`, `none` | What leads each revealed line. |
| `tone` | `ink` | `ink`, `paper` | Ink for light grounds, paper for dark compositions. |

Set them with `data-variable-values` on the element that mounts it. These are the
defaults, so this behaves exactly like the preview above until you change one:

```html wrap
<div
  data-composition-id="line-reveal-list"
  data-composition-src="compositions/components/line-reveal-list.html"
  data-variable-values='{"size":52,"marker":"check","tone":"ink"}'
></div>
```
