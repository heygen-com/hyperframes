## Variables

Every one of these has a default, so the piece works untouched. Set the ones you
want to change on the element:

| Variable | Default | Accepts | What it does |
| --- | --- | --- | --- |
| `value` | `5.7` | string | The number itself. Every character becomes its own span, so the stagger still lands character by character. |
| `unit` | `k` | string | Small suffix printed after the number. Pass an empty string to drop it. |
| `lift` | `standard` | `close`, `standard`, `far` | Scales the offset the timeline drives, so the characters cover a shorter or longer run in the same time. |
| `tone` | `ink` | `ink`, `paper`, `accent` | Number colour: ink for light frames, paper for dark ones, accent rides --brand. |

Set them with `data-variable-values` on the element that mounts it. These are the
defaults, so this behaves exactly like the preview above until you change one:

```html wrap
<div
  data-composition-id="number-pop-in"
  data-composition-src="compositions/components/number-pop-in.html"
  data-variable-values='{"value":"5.7","unit":"k","lift":"standard","tone":"ink"}'
></div>
```

  Paste the markup, CSS and script into a composition. Use the timeline
  integration note at the bottom as the starting point for deterministic GSAP
  animation.

  Variables. The script reads each one, falls back to the declared default on

  it keeps driving one offset, one scale and one blur, and these decide what the
  number is, what colour it is, and how far that offset carries it.

    - value (any text, default 5.7): the number itself. Every character becomes
      its own span, so the stagger still lands character by character.
    - unit (any text, default k): the small suffix printed after the number.
      Pass an empty string to drop it.
    - lift (close | standard | far, default standard): scales the offset the
      timeline drives, so the characters cover a shorter or longer run in the
      same time. The offset is zero at rest, so this one only shows in motion.
    - tone (ink | paper | accent, default ink): number colour. ink is near-black
      for light frames, paper near-white for dark ones, accent rides --brand.
      The suffix follows in the same family.

  On every default the result is identical to the original: 5.7k rising 24px
  through an 8px blur in near-black.
-->

<style>
  .hf-transition-number-pop-in {
    display: inline-flex;
    align-items: baseline;
    gap: 2px;
    color: var(--hf-number-color, #18181b);
    font-family: Inter, system-ui, sans-serif;

    transform: translateY(calc(var(--hf-number-y, 0px) * var(--hf-number-lift, 1)))
      scale(var(--hf-number-scale, 1));
    will-change: transform, filter, opacity;

  .hf-transition-number-pop-in small {

    color: var(--hf-number-unit-color, #71717a);
    font-size: 34px;
    font-weight: 850;
  }

<script>
  (function () {
    "use strict";

    var vars =
      window.__hyperframes && window.__hyperframes.getVariables
        ? window.__hyperframes.getVariables()
        : {};

    // Unrecognised overrides return to their declared defaults.
    var lifts = { close: 0.5, standard: 1, far: 1.75 };
    var tones = {
      ink: { number: "#18181b", unit: "#71717a" },
      paper: { number: "#fafafa", unit: "#a1a1aa" },
      accent: { number: "var(--brand, #34d399)", unit: "var(--brand, #34d399)" },
    };

    function text(value, fallback) {
      return typeof value === "string" ? value : fallback;
    }

    var value = text(vars.value, "5.7");
    if (value === "") value = "5.7";
    var unit = text(vars.unit, "k");
    var lift = Object.prototype.hasOwnProperty.call(lifts, vars.lift) ? vars.lift : "standard";
    var tone = Object.prototype.hasOwnProperty.call(tones, vars.tone) ? vars.tone : "ink";

    var roots = document.querySelectorAll(".hf-transition-number-pop-in");
    for (var i = 0; i < roots.length; i += 1) {
      var root = roots[i];
      root.style.setProperty("--hf-number-lift", String(lifts[lift]));
      root.style.setProperty("--hf-number-color", tones[tone].number);
      root.style.setProperty("--hf-number-unit-color", tones[tone].unit);

      var next = [];
      for (var c = 0; c < value.length; c += 1) {
        var span = document.createElement("span");
        span.textContent = value.charAt(c);
        next.push(span);
      }
      if (unit !== "") {
        var small = document.createElement("small");
        small.textContent = unit;
        next.push(small);
      }
      root.replaceChildren.apply(root, next);
    }
  })();
</script>
