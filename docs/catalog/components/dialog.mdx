## Variables

Every one of these has a default, so the piece works untouched. Set the ones you
want to change on the element:

| Variable | Default | Accepts | What it does |
| --- | --- | --- | --- |
| `width` | `standard` | `compact`, `standard`, `wide` | Panel width, from a tight confirm box to a wide form sheet. |
| `scrim` | `standard` | `light`, `standard`, `blackout` | How dark the backdrop sits behind the panel. |
| `action` | `neutral` | `neutral`, `accent`, `danger` | Fill of the primary button: neutral, accent, or destructive. |

Set them with `data-variable-values` on the element that mounts it. These are the
defaults, so this behaves exactly like the preview above until you change one:

```html
<div
  data-composition-id="dialog"
  data-composition-src="compositions/components/dialog.html"
  data-variable-values='{"width":"standard","scrim":"standard","action":"neutral"}'
></div>
```
