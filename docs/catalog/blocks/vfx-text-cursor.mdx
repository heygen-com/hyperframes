## Install

<InstallCommand command="npx hyperframes add vfx-text-cursor" />

That writes one file: `compositions/vfx-text-cursor.html`.

<Warning>
  Live preview needs the `chrome://flags/#canvas-draw-element` flag switched on.
  Rendering from the CLI switches it on for you. [How it
  works](/guides/html-in-canvas)
</Warning>

## Usage

After installing, add the block to your host composition:

```html
<div data-composition-id="vfx-text-cursor" data-composition-src="compositions/vfx-text-cursor.html" data-start="0" data-duration="8" data-track-index="1" data-width="1920" data-height="1080"></div>
```
