## Install

<InstallCommand command="npx hyperframes add loop-box" item="loop-box" />

That writes one file: `compositions/loop-box.html`.

## Add it to your video

It runs for 12 seconds at 1080×1080. Paste this into your composition:

```html index.html
<div
  data-composition-id="loop-box"
  data-composition-src="compositions/loop-box.html"
  data-start="0"
  data-duration="12"
  data-track-index="1"
  data-width="1080"
  data-height="1080"
></div>
```

Move it in time with `data-start`. Put it on a different timeline row with
`data-track-index`. See [data attributes](/concepts/data-attributes) for the rest.
