## Install

```bash Terminal
npx hyperframes add yt-lower-third
```

That writes `compositions/yt-lower-third.html`, plus 1 supporting file under `assets/`.

## Add it to your video

It runs for 4.5 seconds at 1920×1080. Paste this into your composition:

```html index.html
<div
  data-composition-id="yt-lower-third"
  data-composition-src="compositions/yt-lower-third.html"
  data-start="0"
  data-duration="4.5"
  data-track-index="1"
  data-width="1920"
  data-height="1080"
></div>
```

Move it in time with `data-start`. Put it on a different timeline row with
`data-track-index`. See [data attributes](/concepts/data-attributes) for the rest.
