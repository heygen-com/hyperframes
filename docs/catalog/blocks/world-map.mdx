## Install

```bash Terminal
npx hyperframes add world-map
```

That writes one file: `compositions/world-map.html`.

## Add it to your video

It runs for 14 seconds at 1920×1080. Paste this into your composition:

```html index.html
<div
  data-composition-id="world-map"
  data-composition-src="compositions/world-map.html"
  data-start="0"
  data-duration="14"
  data-track-index="1"
  data-width="1920"
  data-height="1080"
></div>
```

Move it in time with `data-start`. Put it on a different timeline row with
`data-track-index`. See [data attributes](/concepts/data-attributes) for the rest.
