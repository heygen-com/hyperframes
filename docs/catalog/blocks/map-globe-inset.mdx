## Add it to your video

It runs for 9 seconds at 1920×1080. Paste this into your composition:

```html index.html
<div
  data-composition-id="map-globe-inset"
  data-composition-src="compositions/map-globe-inset.html"
  data-start="0"
  data-duration="9"
  data-track-index="1"
  data-width="1920"
  data-height="1080"
></div>
```

Move it in time with `data-start`. Put it on a different timeline row with
`data-track-index`. See [data attributes](/concepts/data-attributes) for the rest.

## Change how it looks

Set these CSS variables on the block:

- `undefined` — Title. Defaults to `World Inset`.
- `undefined` — Subtitle. Defaults to `Educational cartography · globe inset`.
- `undefined` — Accent. Defaults to `#c45c26`.

## Variables

Every one of these has a default, so the piece works untouched. Set the ones you
want to change on the element:

| Variable | Default | Accepts | What it does |
| --- | --- | --- | --- |
| `title` | `World Inset` | string |  |
| `subtitle` | `Educational cartography · globe inset` | string |  |
| `accent` | `#c45c26` | color |  |

Set them with `data-variable-values` on the element that mounts it. These are the
defaults, so this behaves exactly like the preview above until you change one:

```html wrap
<div
  data-composition-id="map-globe-inset"
  data-composition-src="compositions/map-globe-inset.html"
  data-variable-values='{"title":"World Inset","subtitle":"Educational cartography · globe inset","accent":"#c45c26"}'
></div>
```
