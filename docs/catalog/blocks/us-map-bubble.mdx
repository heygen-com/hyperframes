## Install

```bash Terminal
npx hyperframes add us-map-bubble
```

That writes one file: `compositions/us-map-bubble.html`.

## Add it to your video

It runs for 12 seconds at 1920×1080. Paste this into your composition:

```html index.html
<div
  data-composition-id="us-map-bubble"
  data-composition-src="compositions/us-map-bubble.html"
  data-start="0"
  data-duration="12"
  data-track-index="1"
  data-width="1920"
  data-height="1080"
></div>
```

Move it in time with `data-start`. Put it on a different timeline row with
`data-track-index`. See [data attributes](/concepts/data-attributes) for the rest.
