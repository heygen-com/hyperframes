## Install

```bash Terminal
npx hyperframes add transitions-radial
```

That writes one file: `compositions/transitions-radial.html`.

## Add it to your video

It runs for 20 seconds at 1920×1080. Paste this into your composition:

```html index.html
<div
  data-composition-id="transitions-radial"
  data-composition-src="compositions/transitions-radial.html"
  data-start="0"
  data-duration="20"
  data-track-index="1"
  data-width="1920"
  data-height="1080"
></div>
```

Move it in time with `data-start`. Put it on a different timeline row with
`data-track-index`. See [data attributes](/concepts/data-attributes) for the rest.
