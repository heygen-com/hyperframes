## Install

```bash Terminal
npx hyperframes add yt-vertical-fill
```

That writes one file: `compositions/yt-vertical-fill.html`.

## Add it to your video

It runs for 8 seconds at 1920×1080. Paste this into your composition:

```html index.html
<div
  data-composition-id="yt-vertical-fill"
  data-composition-src="compositions/yt-vertical-fill.html"
  data-start="0"
  data-duration="8"
  data-track-index="1"
  data-width="1920"
  data-height="1080"
></div>
```

Move it in time with `data-start`. Put it on a different timeline row with
`data-track-index`. See [data attributes](/concepts/data-attributes) for the rest.
