## Install

<InstallCommand command="npx hyperframes add loop-wheelcarousel" item="loop-wheelcarousel" />

That writes one file: `compositions/loop-wheelcarousel.html`.

## Add it to your video

It runs for 9 seconds at 1080×1080. Paste this into your composition:

```html index.html
<div
  data-composition-id="loop-wheelcarousel"
  data-composition-src="compositions/loop-wheelcarousel.html"
  data-start="0"
  data-duration="9"
  data-track-index="1"
  data-width="1080"
  data-height="1080"
></div>
```

Move it in time with `data-start`. Put it on a different timeline row with
`data-track-index`. See [data attributes](/concepts/data-attributes) for the rest.
