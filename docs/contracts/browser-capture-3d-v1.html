The representation decision

A · recommended

Live 3D island inside editable DOM

Keep artifact.kind = editable-dom. A model placeholder consumes one local GLB resource. Mixed text, buttons, and 3D remain one capture.

B

New editable-3d artifact

Clean for model-only selections, but fractures mixed captures and duplicates placement, identity, and persistence rules.

C

Attach GLB behind a Still

Preserves the screenshot first, but the thing on canvas is not the editable model. This fails the product promise.

One owner per boundary

Discover

The content script sees completed same-origin .glb or .gltf resources associated with a selected canvas.

Validate

Core owns GLB magic, declared length, embedded URI, hash, and byte-budget validation.

Transport

The canonical clipboard envelope carries model bytes. No token, signed URL, or page code is copied.

Persist

Studio writes the model plus child composition as one operation, then inserts the timeline host.

Render

A version-pinned HyperFrames viewer owns camera, orbit, materials, decoder support, and deterministic frame rendering.

What editable means

Editable now

Scene controls

Position, rotation, scale, camera orbit, focal length, environment, exposure, material parameters, and animation-clip playback.

Preserved

Model structure

Meshes, nodes, PBR materials, embedded textures, model extensions, and named animation clips survive as real glTF data.

Not promised

Vertex editing

Studio is not Blender. Direct mesh topology editing, UV unwrapping, rig authoring, and sculpting remain out of scope.

Acceptance gates

The live UltraMock canvas produces a GLB-backed placeholder, not an image-only opaque island.
The model still renders after the source tab closes and network access is disabled.
Changing camera orbit or model rotation in Studio changes the rendered frame.
Reloading Studio preserves the local model, its controls, and the timeline placement.
Unsupported or oversized models fall back to the existing local visual island with an explicit diagnostic.
No third-party model bytes are committed to this repository or shipped in test fixtures.
