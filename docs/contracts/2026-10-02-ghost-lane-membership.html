How it says no

SignalMeaning and response
Locked shifted clipInsertion returns without persistence. Existing permission rules remain the owner.
Save rejectionThe file transaction restores already-written snapshots and rethrows. The optimistic clip rollback must restore membership alongside timing and track.
Undo content mismatchHistory refuses to overwrite a file changed since the edit and reports the conflict.

Decision already supplied

New tracks outside a group detach the dragged clip. Drops onto member tracks retain existing behavior. Cmd+Z restores membership. There is no open product decision.

What would prove this page wrong

Drop a grouped clip at a group edge, reload the file, then Cmd+Z. The clip must lose membership after the drop, occupy the promised lane, and regain its original track and membership in one undo. A member-track drop must retain membership.
