Idle against the document's own frame gaps

Keep the timeline in step with the picture while removing the slow-document readiness hold.

In one breath. Core owns the paint-and-idle decision; the player exposes readiness only after loader clearance, and Studio commits the shadow timeline when that picture becomes live.

Where the value travels

Document frame timestamps → core settlement → player assetsready → loader hidden → painted → Studio readyToShow → shadow promotion and timeline commit

How it says no

SignalMeaning and action
nullNo document window, no paint input is pending.
AbortSignalShared timeout or completion cancels remaining frame requests.
timedOut: trueShared 8-second wait elapsed. Player warns and continues; this is not proof of idle.
Generation mismatchOld load cannot mark the current picture ready.

Chosen rule after measurement

1.5x the shortest gap in the current readiness attempt

Fast gaps retain the strict < 50 ms comparison, including zero timestamps. Above that path, two consecutive relative gaps must qualify. A slower gap resets the streak. The existing paint cap, shared timeout and abort semantics remain.

1.5x is the smallest tested tolerance that covers every ordinary window. The baseline belongs to one bounded readiness attempt and never rises during that attempt. These are overlapping nine-gap windows from nine controlled browser traces, excluding windows containing the deliberately injected burst. They are not independent trials. The injected 250 ms gap exceeds the selected threshold.

Sixfold CPU throttling, inline content and 60 ms frame work: main settles steady-slow in 1682 to 1701 ms, jittered in 1652 to 1703 ms, and burst/recovery in 1637 to 1686 ms. Candidate: 348 to 361 ms, 361 to 364 ms and 595 to 602 ms respectively, three runs each. Timer begins before the first workload; these wall times include that work and scheduling. Concurrent machine activity limits absolute timing claims.

Stable cadence is not proof of completed computation. The separate compute, media, loader and generation gates retain their authority.
