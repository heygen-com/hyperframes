## Variables

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `label_a` | `string` | `Draft` | Label on the card that begins in focus. |
| `label_b` | `string` | `Published` | Label on the card that receives focus. |
| `accent` | `enum` | `blue` | Highlight color shared by both cards. |

## When to use it

Two cards at different apparent depths need one clear handoff from the foreground state to the background state.

## When to avoid it

Avoid it when focus must alternate repeatedly, because the rack occurs exactly once over 0.7 seconds.
