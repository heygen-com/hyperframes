## Variables

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `states` | `string` | `Queued,Reading,Drafting,Done` | Comma-separated chip labels in machine order (2 to 8 states). |
| `times` | `string` | `""` | Comma-separated activation times in seconds, one per advance (state 1 onward). Blank entries use the default even rhythm. |
| `badge_state` | `number` | `1` | Index of the state the badges pop beside. |
| `badges` | `string` | `""` | Comma-separated badge labels shown beside the badge state. Empty disables. |
| `accent` | `enum` | `green` | Accent token family used by the active chip. |
| `exit` | `enum` | `none` | How the rail leaves the frame. Default none: the hold ends the film. |

## When to use it

A discrete state machine needs seek-exact, instantaneous advances and optional badges beside one activated state.

## When to avoid it

Avoid it when more than eight states or more than four badges are required, because extra states are dropped and badges are capped at four.
