## Variables

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `text` | `string` | `Ship it with confidence` | Full line of display text. |
| `emphasis_word` | `string` | `confidence` | First case-insensitive substring match in text receives the marker. Empty or unmatched draws no marker. |
| `style` | `enum` | `highlight` | Shape of the hand-drawn marker stroke. |
| `draw_at` | `number` | `0.9` | Second (from mount start) the marker starts drawing. Clamped so the stroke completes before any exit. |
| `accent` | `enum` | `green` | Marker ink color from the contract token map. |
| `exit` | `enum` | `none` | Optional departure. Default none: the lockup holds until the frame cuts. |

## When to use it

One specific word or short phrase in a single line needs a timed highlight, circle, underline, or scribble.

## When to avoid it

Avoid it when the emphasized phrase must wrap, because the header requires the match to stay on one line.
