## Variables

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `sketch` | `enum` | `bulb` | Authored preset sketch to draw. Ignored when the strokes slot holds custom paths. |
| `caption` | `string` | `Draw the idea` | Short line shown after the sketch completes. |
| `pen` | `enum` | `show` | Show or hide the pen nib actor. |
| `accent` | `enum` | `green` | Color used by strokes marked data-ink=accent (one highlight stroke in each preset). |
| `exit` | `enum` | `none` | How the completed lockup leaves. none holds the final frame. |

## When to use it

A preset or caller-supplied SVG sketch needs sequential ink drawing with a traveling pen actor and a caption after completion.

## When to avoid it

Avoid supplying non-path slot content, because only path elements inside the strokes group become the drawing.
