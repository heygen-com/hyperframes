## Variables

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `dot_size` | `enum` | `medium` | Grid pitch for the halftone field. |
| `direction` | `enum` | `ltr` | Threshold ordering: ltr sweeps left to right, center grows from the middle, noise scatters. |
| `dissolve_at` | `number` | `1.1` | Seconds from mount start when the dissolve begins. |
| `accent` | `enum` | `green` | Ink dot color: green rides --brand, blue rides --accent, violet rides --accent-2. |
| `exit` | `enum` | `none` | Optional departure. Default none: scene B holds until the frame cuts. |

## When to use it

Two slotted scenes need a textured transition whose reveal can sweep left to right, grow from center, or scatter from a seeded map.

## When to avoid it

Avoid cueing the dissolve so late that its 1.3-second transition and any exit cannot fit, because dissolve_at is clamped to keep both inside the clip.
