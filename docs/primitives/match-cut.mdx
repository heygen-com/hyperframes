## Variables

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `accent` | `enum` | `green` | Color shared by the matched circles. |
| `label_a` | `string` | `Start` | Text inside the outgoing button. |
| `label_b` | `string` | `Done` | Result text revealed after the cut. |

## When to use it

Two scenes share a circle that can carry motion continuously across a precise hard cut.

## When to avoid it

Avoid it when a crossfade is required, because scene A becomes invisible and scene B visible at the same timeline instant.
