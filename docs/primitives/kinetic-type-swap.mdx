## Variables

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `prefix` | `string` | `Ship` | Fixed sentence text before the rolling word slot. |
| `options` | `string` | `faster,smarter,together` | Comma-separated words shown in the rolling slot. |
| `suffix` | `string` | `""` | Fixed sentence text after the rolling word slot. |
| `cues` | `string` | `""` | Comma-separated seconds (from mount start) for each word swap. Empty keeps the authored even spread. |
| `accent` | `enum` | `green` | Color used by the rolling word slot. |
| `exit` | `enum` | `none` | Optional departure. Default none: the sentence holds until the frame cuts. |

## When to use it

A headline must keep its prefix and suffix stationary while one word changes through several authored choices.

## When to avoid it

Avoid it when the sentence may reflow during a swap, because the slot is pre-sized to the widest option and all options occupy one grid cell.
