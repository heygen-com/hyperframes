# HyperFrames v0.8.50

Released on 2026-09-19.

Compositions that use a `<canvas>` — Three.js, shaders, charts — no longer lose their Studio editing session. The timeline also moves to one row per top-level element, and gains copy, paste and duplicate for clip groups.

## Features

- **Studio:** The timeline shows one row per top-level element and no child rows ([7797c5ead](https://github.com/heygen-com/hyperframes/commit/7797c5ead4c0ecd41745b3be9b8f5a266762e603), [#4132](https://github.com/heygen-com/hyperframes/pull/4132)).
- **Studio:** Preview ruler and safe-margin toggles ([898d27869](https://github.com/heygen-com/hyperframes/commit/898d27869ea16aeb6e58d7f6fe0ef1267ccbfe30), [#4127](https://github.com/heygen-com/hyperframes/pull/4127)).
- **Studio:** Add per-project UI preference scoping ([a192701ad](https://github.com/heygen-com/hyperframes/commit/a192701adb118e510d6c4f284108e99f2e37ed85), [#4093](https://github.com/heygen-com/hyperframes/pull/4093)).
- **Studio:** The agent sees every timeline clip, audio included ([6995a4c2f](https://github.com/heygen-com/hyperframes/commit/6995a4c2f7a5ce5df9553920f82e8fbadebe928d), [#4123](https://github.com/heygen-com/hyperframes/pull/4123)).
- **Parsers:** Share top-level timeline element and track kind definitions ([02c415dd8](https://github.com/heygen-com/hyperframes/commit/02c415dd8b531783130aa5b66c1c0df94f6b29ba), [#4124](https://github.com/heygen-com/hyperframes/pull/4124)).
- **Studio:** Copy, paste and duplicate clip groups on the timeline ([0b6d1039e](https://github.com/heygen-com/hyperframes/commit/0b6d1039ed0a799fd088fd7af8a4b9440208e23a), [#4064](https://github.com/heygen-com/hyperframes/pull/4064)).
