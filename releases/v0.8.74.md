# HyperFrames v0.8.74

Released on 2026-09-24.

Every change to a project is now kept in a history you can undo or restore. A play() during loading now plays, and new lint warnings catch invisible layers and zoomed canvases.

## Features

- **Studio Server:** Every write to a project is kept in a history that can be undone or restored ([56c48a79be](https://github.com/heygen-com/hyperframes/commit/56c48a79beca307bbc05c2b0e70da47d933d6180), [#4431](https://github.com/heygen-com/hyperframes/pull/4431)).
- **CLI:** Warn when canvas content touches the frame edge ([7556b95ac6](https://github.com/heygen-com/hyperframes/commit/7556b95ac6ab7ab43e0c6973dd7673bb839434a9), [#4427](https://github.com/heygen-com/hyperframes/pull/4427)).
- **Lint:** Warn on negative z-index, which renders invisibly behind the root ([42ae3da5b6](https://github.com/heygen-com/hyperframes/commit/42ae3da5b6c54a6138ace2b983252d363df170d5), [#4403](https://github.com/heygen-com/hyperframes/pull/4403)).
- **Lint:** Warn when a composition is wider than the inspection viewport cap ([5325891726](https://github.com/heygen-com/hyperframes/commit/532589172675dc710c28b43b2c65c6a9a3bc8ab5), [#4413](https://github.com/heygen-com/hyperframes/pull/4413)).
- **Lint:** Flag a canvas-level CSS zoom that rescales a fixed frame ([201c829c45](https://github.com/heygen-com/hyperframes/commit/201c829c454dc55582cd0e01a7487228959d88d8), [#4412](https://github.com/heygen-com/hyperframes/pull/4412)).
