# HyperFrames v0.8.211

Released on 2026-10-28.

Graded clips now draw on real GPUs instead of showing a blank frame, including clips zoomed far past the screen. New blank projects also start on black, not grey. Renders are faster in many places, and cloud renders stitch in parallel.

## Features

- **Core:** The preview says why a choppy stretch dropped frames.
- **CLI:** Every command is defined the same way and tested as an agent would use it.

- **CLI:** Local servers never bind a port Chromium refuses to load from ([bf7ebe961](https://github.com/heygen-com/hyperframes/commit/bf7ebe961e522533fbbd9b94384198d662935ef5), [#6620](https://github.com/heygen-com/hyperframes/pull/6620)).
- **Dx:** Unblock lint and the Claude pre-commit hook on Windows ([310488b05](https://github.com/heygen-com/hyperframes/commit/310488b0501e17a6e92db646575cdef54251f880), [#6619](https://github.com/heygen-com/hyperframes/pull/6619)).
- **CLI:** A new blank project starts on a black frame, not grey ([4f0bdfb52](https://github.com/heygen-com/hyperframes/commit/4f0bdfb520a7ccb54ca5a602936a3dd713089151), [#6614](https://github.com/heygen-com/hyperframes/pull/6614)).
- **Core:** A graded clip's canvas no longer comes out blank on a real GPU ([9eaf9efb6](https://github.com/heygen-com/hyperframes/commit/9eaf9efb69f37de0d6d98324bda1c65c9a924f2f), [#6615](https://github.com/heygen-com/hyperframes/pull/6615)).

- **Studio Server:** Undo and redo on Windows work on a file another program holds open.

## Performance

- **CLI:** Check's craft pass skips clips the runtime has hidden ([815ff9ec8](https://github.com/heygen-com/hyperframes/commit/815ff9ec8d755b52c050943765bf15c9c9b1e88e), [#6627](https://github.com/heygen-com/hyperframes/pull/6627)).
- **Producer:** GPU renders encode while frames are still being captured.
- **AWS Lambda:** Small-chunk cloud renders stitch their output in parallel.
- **Engine:** A GPU render checks the GPU encoders once, not twice.
- **Engine:** Macs with a hardware GPU render with more capture workers.
- **Producer:** A remote video is downloaded once per render.
- **Producer:** The audio mix runs while capture starts its browsers.
- **Producer:** Films that draw elements keep their parallel workers instead of dropping to one.
- **Producer:** Worker sizing measures screenshot capture and starts one browser fewer.
- **Studio:** Timeline thumbnails share video sources and keep their frames.
