# HyperFrames v0.8.121

Released on 2026-10-04.

Media Use no longer crashes when a HeyGen credentials path is a folder. Video length and size now come from one place in the core runtime.

- **Media Use:** Skip a .env folder when loading HeyGen credentials ([5f3191bdc593](https://github.com/heygen-com/hyperframes/commit/5f3191bdc59312b6d6cba231e50207919e22b7cf), [#4988](https://github.com/heygen-com/hyperframes/pull/4988)).
