# HyperFrames v0.8.143

Released on 2026-10-08.

Distributed renders of long videos start much sooner. Each chunk now extracts only the video frames it shows, instead of the plan step extracting every frame up front. On AWS Lambda, a 26-minute clip now plans in about 20 seconds instead of over 6 minutes.

This release also fixes WebVTT caption parsing, makes `hyperframes check` and lint more accurate, and fixes SDK save and patch edge cases.
