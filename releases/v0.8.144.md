# HyperFrames v0.8.144

Released on 2026-10-10.

Previews are steadier and the CLI is more reliable on Windows. Small previews keep every layer, a looping scene no longer plays past the film's end, and transcribe can write SRT or VTT directly.

## Features

- **CLI:** Let transcribe --to write srt or vtt straight from a media file ([908f4395b](https://github.com/heygen-com/hyperframes/commit/908f4395b4d05a3969bdc53a7cc89cea0d48e8ff), [#5215](https://github.com/heygen-com/hyperframes/pull/5215)).
- **CLI:** Models list shows which speech models transcribe can use ([0576b24c7](https://github.com/heygen-com/hyperframes/commit/0576b24c75a604deb9c909407b8328b3df17b0c1), [#5323](https://github.com/heygen-com/hyperframes/pull/5323)).
