# HyperFrames v0.8.94

Released on 2026-09-30.

Editing in Studio now does what you expect more often. Corner drags on small elements resize them, text selection keeps the edit open, and resizing a moving element no longer adds keyframes. Apps that embed Studio can also turn off body drags and choose how the timeline looks.

## Features

- **Studio:** A host can turn off body drags and keep the resize, rotate and crop handles ([ac754b25d](https://github.com/heygen-com/hyperframes/commit/ac754b25d0c05a5de042d4fcacb6969629c7701c), [#4732](https://github.com/heygen-com/hyperframes/pull/4732)).
- **Studio:** Let a host hide timeline history, place the shortcuts button and set track padding ([26db30701](https://github.com/heygen-com/hyperframes/commit/26db3070161c4b6d98fb9cbb15db4f9d9a7644c1), [#4739](https://github.com/heygen-com/hyperframes/pull/4739)).
