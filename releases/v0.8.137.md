# HyperFrames v0.8.137

Released on 2026-10-06.

Compositions with large inline images or scripts use far less memory while they load for preview. Whisper transcription detects the spoken language and can report progress.

## Fixes

- **Studio:** Audio clips that reach the export ceiling now say “Too loud”, with the exact peak on hover or keyboard focus ([4905b4dbc](https://github.com/heygen-com/hyperframes/commit/4905b4dbca74ddff8e9302a0fe00fa74ddd7d056), [#5099](https://github.com/heygen-com/hyperframes/pull/5099)).
- **Core:** Large inline images and scripts use far less memory while a composition loads ([00342fc2b](https://github.com/heygen-com/hyperframes/commit/00342fc2be0a9905dd67cc218d713aeca19b5e3f), [#5098](https://github.com/heygen-com/hyperframes/pull/5098)).
- **CLI:** With Whisper, `transcribe` detects the spoken language instead of assuming English, and `--json` reports download and transcription progress. The new `--no-runtime-install` flag stops it installing the Whisper runtime ([1db44c659](https://github.com/heygen-com/hyperframes/commit/1db44c659565a5a70a39fbe836c497afe9a84d6d), [#5103](https://github.com/heygen-com/hyperframes/pull/5103)).
