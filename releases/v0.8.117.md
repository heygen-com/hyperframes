# HyperFrames v0.8.117

Released on 2026-10-04.

Edits in Studio now stay where you put them: resizes, rotations, undo and drops on animated layers all save and redraw correctly. A render with a broken video frame now fails loudly instead of hiding a blank frame.

## Fixes

- **Studio:** Undoing a freeze frame removes the still it made ([237a984bb8d9](https://github.com/heygen-com/hyperframes/commit/237a984bb8d97f8dff7a5464c78851d633747f54), [#4971](https://github.com/heygen-com/hyperframes/pull/4971)).
- **Engine:** Fail the render when an injected video frame cannot decode ([8e457d4224c5](https://github.com/heygen-com/hyperframes/commit/8e457d4224c513a8cdcb11b7d63aa204f5af7e0c), [#4974](https://github.com/heygen-com/hyperframes/pull/4974)).
- **Parsers:** A keyframe edit no longer overrides an earlier tween at the start ([b71aa9338be1](https://github.com/heygen-com/hyperframes/commit/b71aa9338be16edd77ac78392dc95045ac1b4f70), [#4935](https://github.com/heygen-com/hyperframes/pull/4935)).
- **Studio:** A rotation saves through its press route; a host hook reloads only the host's way ([910677259364](https://github.com/heygen-com/hyperframes/commit/9106772593648367ef5a595171f6cfe570ef99d5), [#4961](https://github.com/heygen-com/hyperframes/pull/4961)).
- **Skills:** Load shared creative guides for motion graphics ([9031a02cb53d](https://github.com/heygen-com/hyperframes/commit/9031a02cb53d6c1eff7b4ed83b81ed4ee2325508), [#4970](https://github.com/heygen-com/hyperframes/pull/4970)).
- **Studio:** An undo or drop on an animated layer keeps it where it was ([2cfbe3d2570c](https://github.com/heygen-com/hyperframes/commit/2cfbe3d2570cee5a7499323c9e9c2cadaa160bb2), [#4934](https://github.com/heygen-com/hyperframes/pull/4934)).
- **Studio:** A resize saves through the route its press chose, as a move does ([e27cae026190](https://github.com/heygen-com/hyperframes/commit/e27cae02619037cc01299fe86877ade974c1b3bb), [#4943](https://github.com/heygen-com/hyperframes/pull/4943)).
