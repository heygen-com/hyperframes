# HyperFrames v0.8.107

Released on 2026-10-02.

Manual editing in Studio is far more reliable: resizes, crops and drops survive undo and reload, and undo works right after an edit or during a drag. Apps that embed Studio can also run its agent tools on their own edit session, and a video's sound now stays on its clip by default.

## Features

- Keep a video's sound on the clip by default (1/8) ([37f30b1d06c](https://github.com/heygen-com/hyperframes/commit/37f30b1d06c41b4ef4579e456bfe6c6aeaaa0611), [#4813](https://github.com/heygen-com/hyperframes/pull/4813)).
- **Studio:** Hosts can run Studio's agent tools on their own edit session ([7a60b97bf8c](https://github.com/heygen-com/hyperframes/commit/7a60b97bf8c2bb6a6f90956316eef8fd0de5060f), [#4882](https://github.com/heygen-com/hyperframes/pull/4882)).
