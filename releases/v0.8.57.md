# HyperFrames v0.8.57

Released on 2026-09-20.

Studio now says which project it is actually serving when a link points at one it cannot open, instead of failing quietly. Links to a project that was renamed or deleted are caught as you navigate, and the address bar is corrected.

- **Studio:** Say which project this Studio is serving when a read 404s ([f476e78cc](https://github.com/heygen-com/hyperframes/commit/f476e78cc83d7fe4b5c28a769157e59eeba80812), [#4228](https://github.com/heygen-com/hyperframes/pull/4228)).
- **Studio:** A per-page tab id, and the hash-validation verdict ([7abbe4963](https://github.com/heygen-com/hyperframes/commit/7abbe49638ce2f210ffb812d171146ff312dbb4b), [#4224](https://github.com/heygen-com/hyperframes/pull/4224)).
