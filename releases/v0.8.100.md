# HyperFrames v0.8.100

Released on 2026-10-01.

Moving or nudging an element in Studio is exact when it has no GSAP animation. It lands where you drop it and is saved as plain CSS, with no GSAP script added. A text edit saves to the element you edited, or tells you why it could not.
