# HyperFrames v0.8.142

Released on 2026-10-08.

The CLI now accepts a HeyGen access token handed over by a host app, so the app can sign it in without saving credentials. If your shell already exports `HEYGEN_ACCESS_TOKEN`, the CLI now uses it ahead of `~/.heygen/credentials`.
