# HyperFrames v0.8.84

Released on 2026-09-28.

Studio keeps the words you typed when the editor closes mid-edit, and HEVC clips no longer stall it while their preview copies are made. Host apps can import id stamping, file walking and history without the server.

## Fixes

- **Studio:** Words typed mid-edit are saved when the editor closes, as they are when you click away ([42f6a3a27](https://github.com/heygen-com/hyperframes/commit/42f6a3a27e57d6bb6373d11169d5e7a4cd5bfbe5), [#4651](https://github.com/heygen-com/hyperframes/pull/4651)).
- **Studio:** The timeline reads clip speed with the same limits as playback ([523685985](https://github.com/heygen-com/hyperframes/commit/523685985b4aaa4e4e017486b287d9500627f3ef), [#4667](https://github.com/heygen-com/hyperframes/pull/4667)).
- **Studio Server:** HEVC clips no longer stall Studio while their preview copies are made ([cbcadbfbd](https://github.com/heygen-com/hyperframes/commit/cbcadbfbd089de11fe30f1054fdcf54956aad780), [#4580](https://github.com/heygen-com/hyperframes/pull/4580)).

## Performance
