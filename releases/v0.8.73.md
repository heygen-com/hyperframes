# HyperFrames v0.8.73

Released on 2026-09-24.

Trimming a scene in Studio keeps its length, and an edit reaches the preview even when a reload is slow. Renders report progress from the first frame, and projects whose names contain @, %, #, & or ? now load.

## Features

- **Studio:** An embedder can change what the shortcuts panel lists ([881481f56](https://github.com/heygen-com/hyperframes/commit/881481f56b2682a62dc64b75a1237bc5e06a9bb7), [#4416](https://github.com/heygen-com/hyperframes/pull/4416)).
