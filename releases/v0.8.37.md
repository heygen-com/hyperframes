# HyperFrames v0.8.37

Released on 2026-09-13.

Bundled HTML now embeds supported fonts and images up to 2 MiB each, so they remain available without the project folder. This release also fixes missing clips, shifting video layouts, render recovery on low disk space, and AAC audio peak correction.

## Fixes

- **Bundling:** Embed supported local fonts and raster images up to 2 MiB each in bundled HTML. Larger assets warn and remain external, as do audio and video ([cd975d8c2](https://github.com/heygen-com/hyperframes/commit/cd975d8c2805acc78542a68433271f771352de23), [#3590](https://github.com/heygen-com/hyperframes/pull/3590)).
- **Rendering:** When capture verification fails, use the available streaming fallback if saving frames to disk would exceed available storage ([4c26ffe8c](https://github.com/heygen-com/hyperframes/commit/4c26ffe8ce910ae1b3a41479192f613a6a4bd75b), [#3703](https://github.com/heygen-com/hyperframes/pull/3703)).
- **Video layout:** Keep inactive nested videos out of the layout so neighboring videos do not shift during rendering ([fdf9ffac9](https://github.com/heygen-com/hyperframes/commit/fdf9ffac953d9d18329907d6956faa58c73ad489), [#3639](https://github.com/heygen-com/hyperframes/pull/3639)).
- **Clip visibility:** Show later root-level clips when their start time arrives, even if the runtime previously hid them ([1acc65dbf](https://github.com/heygen-com/hyperframes/commit/1acc65dbf813d5750c241c7e6e15b48329271ffb), [#3893](https://github.com/heygen-com/hyperframes/pull/3893)).
- **Audio:** Leave extra headroom when correcting AAC peaks so re-encoding is less likely to push them back above the delivery limit. Failed corrections now report measurements ([58707afaa](https://github.com/heygen-com/hyperframes/commit/58707afaa04371b1d2cd7b5ff9154804add7f652), [#3693](https://github.com/heygen-com/hyperframes/pull/3693)).

## Docs & Examples
