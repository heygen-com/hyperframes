# HyperFrames v0.8.189

Released on 2026-10-23.

Renders with many audio clips, opaque ProRes video and different host sizes now behave the same everywhere. Studio history also works on drives without hard links.

## Fixes

- **Engine:** An opaque ProRes clip extracts to jpg frames, only ProRes with alpha stays png ([bd4cae7e3](https://github.com/heygen-com/hyperframes/commit/bd4cae7e3582e2da9eee3903bc0780d9d03c98b2), [#6130](https://github.com/heygen-com/hyperframes/pull/6130)).
- **Engine:** Encode with the same x264 and x265 thread count on any host size ([132a504b6](https://github.com/heygen-com/hyperframes/commit/132a504b692bad71d55fa29dc1086f33c3e6aaf3), [#6127](https://github.com/heygen-com/hyperframes/pull/6127)).
- **Studio Server:** The history lock works on drives without hard links ([2ed882ccf](https://github.com/heygen-com/hyperframes/commit/2ed882ccf22fdf070e21442e0437b3ae57253405), [#6125](https://github.com/heygen-com/hyperframes/pull/6125)).
- **Engine:** Mix any number of audio clips by summing them in stages ([3cdae3804](https://github.com/heygen-com/hyperframes/commit/3cdae3804e5f155903adfce32ddf81db290c04b3), [#6120](https://github.com/heygen-com/hyperframes/pull/6120)).
