# HyperFrames v0.8.79

Released on 2026-09-26.

Studio feels faster: a paused preview goes quiet, playback no longer re-renders the whole app, and an edit can swap one scene into the running preview. Many fixes keep saves, undo, audio and the picker in step with what you see.

## Features

- **Core:** The runtime reports where a composition's animations end, one cycle each ([e0e6442d9](https://github.com/heygen-com/hyperframes/commit/e0e6442d9c5935867365c15b598302c750378f2a), [#4541](https://github.com/heygen-com/hyperframes/pull/4541)).
- **Studio Server:** History can copy the files before or after any change into a folder ([7c017a08d](https://github.com/heygen-com/hyperframes/commit/7c017a08de35e013beaee0f388afec7a6e4280bf), [#4493](https://github.com/heygen-com/hyperframes/pull/4493)).
