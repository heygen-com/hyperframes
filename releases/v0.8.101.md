# HyperFrames v0.8.101

Released on 2026-10-01.

Undo and redo in Studio are faster and more exact. They show on the next frame, and one Cmd+Z in the preview takes one step. Timeline drops on an empty lane start at 0 and snap to clip edges.

## Features

- **Studio:** A host app can mount the dock with its own panels, storage key and width ([7719f973c](https://github.com/heygen-com/hyperframes/commit/7719f973c059f4f54ef804b32a0e5746ff6c9a2f), [#4812](https://github.com/heygen-com/hyperframes/pull/4812)).
