# HyperFrames v0.8.190

Released on 2026-10-23.

Motion blur now picks a cheaper way to draw when it can, and renders use less memory. Studio gains a preview seek bar, and an idle editor stops waking the GPU.

## Features

- Automatic tier, 240°/32 defaults, check finding, and Studio stops opting out ([79b57ab12](https://github.com/heygen-com/hyperframes/commit/79b57ab12dfdd4e84536af7f227401f6fac24a60), [#6108](https://github.com/heygen-com/hyperframes/pull/6108)).
- **Core:** Capture blur falls back to per-element filters where capture cannot run ([4ed781338](https://github.com/heygen-com/hyperframes/commit/4ed78133873540ca10366b1230d973dc31ae2ddf), [#6107](https://github.com/heygen-com/hyperframes/pull/6107)).
- **Studio:** Add a preview seek bar ([2512642d0](https://github.com/heygen-com/hyperframes/commit/2512642d09d3d5a4703fd2e6af71930a52e6c7ca), [#6103](https://github.com/heygen-com/hyperframes/pull/6103)).
