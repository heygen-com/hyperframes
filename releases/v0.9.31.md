# HyperFrames v0.9.31

Released on 2026-11-10.

In Safari, long videos no longer load the whole file at once, and playing clips keep their source. The Studio dev server now checks the Host on its API routes, so a tunnel or remote setup may need one setting.

## Fixes

- **Core:** In Safari, a small video file keeps its preload, and a clip that is playing keeps its source ([cda84222a](https://github.com/heygen-com/hyperframes/commit/cda84222aa12716f2ceb92b45629487be81a0601), [#7498](https://github.com/heygen-com/hyperframes/pull/7498)).
- **Studio:** The Studio dev server now checks the Host header on its API routes too, as the preview server does since 0.9.30. A tunnel, Codespaces or remote dev host that worked before can now get a 403: name the host in `HYPERFRAMES_PREVIEW_ALLOWED_HOSTS` (comma separated), which now also reaches the dev server's own allowed hosts ([b0835262a](https://github.com/heygen-com/hyperframes/commit/b0835262ae5179f27d95ac2d140298f83fbf2fd1), [#7493](https://github.com/heygen-com/hyperframes/pull/7493)).
- **Studio Server:** Thumbnail links take their origin from the server, and previews from other sites open sandboxed ([983e865ad](https://github.com/heygen-com/hyperframes/commit/983e865ad7ac8e6e6737eff229949d181934ed39), [#7492](https://github.com/heygen-com/hyperframes/pull/7492)).
- **Producer:** A render that loads the default GSAP file from the CDN uses the copy the CLI already ships, so it works with no network ([5c5799975](https://github.com/heygen-com/hyperframes/commit/5c579997562578a6b0a946d10b4410a23e5f4029), [#7388](https://github.com/heygen-com/hyperframes/pull/7388)).
- **CLI:** The message about another install shadowing this one only names an install its package manager can move ([b28bd2b34](https://github.com/heygen-com/hyperframes/commit/b28bd2b3482a6bcb04d0d0ba0eaee74fbb965455), [#7499](https://github.com/heygen-com/hyperframes/pull/7499)).
- **Studio:** Messages that count clips or keyframes say 1 clip, not 1 clips ([ec30de062](https://github.com/heygen-com/hyperframes/commit/ec30de06278300882a898f5fa0b27a599e0dd550), [#7496](https://github.com/heygen-com/hyperframes/pull/7496)).
- **Studio Server:** When a file is still changing, a claim waits for its first copy, so the edit can still be undone ([248f56fba](https://github.com/heygen-com/hyperframes/commit/248f56fbaa08aa9167ff44b10764df526c90a921), [#7497](https://github.com/heygen-com/hyperframes/pull/7497)).
