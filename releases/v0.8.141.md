# HyperFrames v0.8.141

Released on 2026-10-08.

Renders no longer fail when a page links a Google font with axis values the family lacks. Studio previews of hard-to-play videos decode at their on-screen size.

## Changes

- A font whose Google Fonts link returns no usable faces now falls back to the standard weight request, so renders keep the font instead of failing. ([#5186](https://github.com/heygen-com/hyperframes/pull/5186)).
- Unresolved-font errors carry structured diagnostics about which resolver step failed, without font names, URLs or page text. ([#5189](https://github.com/heygen-com/hyperframes/pull/5189)).
- The player loads compositions using the document's own duration and reports the first author error. ([#5176](https://github.com/heygen-com/hyperframes/pull/5176)).
- Studio decodes HEVC and ProRes previews at the size they appear on screen, so back-to-back 4K clips no longer flash the background. ([#5184](https://github.com/heygen-com/hyperframes/pull/5184)).
- media-use can reach HeyGen through a host app's gateway with `HEYGEN_API_BASE`. ([#5181](https://github.com/heygen-com/hyperframes/pull/5181)).
