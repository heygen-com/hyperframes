# HyperFrames v0.8.122

Released on 2026-10-04.

Studio trims keep the playhead still and clips snap to the ruler, and a host can show its own Split key. Renders wait for web fonts, so text-sized layouts repeat exactly. Media Use gives clearer credential errors and no longer leaves empty assets after a slow download.
