# HyperFrames v0.8.123

Released on 2026-10-04.

Studio gets an Edit with Framey button, and `hyperframes open` opens HyperFrames Studio. Dragging a keyframed layer and redrawing the preview now keep animations where you left them.

## Features

- **Studio,cli:** Add an Edit with Framey button and `hyperframes open` for HyperFrames Studio ([bd0dc8c3aeb0](https://github.com/heygen-com/hyperframes/commit/bd0dc8c3aeb08868f15a95631e5aab7790cce926), [#4951](https://github.com/heygen-com/hyperframes/pull/4951)).

- **Studio Server:** History never files a hidden file as a change ([cad3db47d2d3](https://github.com/heygen-com/hyperframes/commit/cad3db47d2d38b3c083a7340140e0fd59a864c98), [#4966](https://github.com/heygen-com/hyperframes/pull/4966)).
- **Core:** The preview redraw leaves animations after the playhead as the seek drew them ([805cf60b036b](https://github.com/heygen-com/hyperframes/commit/805cf60b036b5357e0dfaba9e91135063a6c2b21), [#4997](https://github.com/heygen-com/hyperframes/pull/4997)).
