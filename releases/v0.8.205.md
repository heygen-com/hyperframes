# HyperFrames v0.8.205

Released on 2026-10-26.

On Windows, hyperframes now offers to download the HyperFrames app, and hyperframes followed by a folder opens that project in it. Studio can also export a GIF with a loop count.

## Features

- **CLI:** Offer the HyperFrames app download on Windows ([b76b529372480](https://github.com/heygen-com/hyperframes/commit/b76b529372480833a851101c24852054589ec8a4)).
- **CLI:** Hyperframes <dir> opens the project in the app ([324671829f40f](https://github.com/heygen-com/hyperframes/commit/324671829f40f719b445290594597086e1cd7798), [#6426](https://github.com/heygen-com/hyperframes/pull/6426)).
- **Studio:** Support GIF export with loop count ([2d695a8436e27](https://github.com/heygen-com/hyperframes/commit/2d695a8436e27a9bba0a989eb83e41efeb779e7c), [#5593](https://github.com/heygen-com/hyperframes/pull/5593)).
