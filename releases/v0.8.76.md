# HyperFrames v0.8.76

Released on 2026-09-25.

Undo and redo in Studio now step through every project change, whoever made it. Studio opens a large film in about 4 s, and a player set to `low-power-idle` stays light while paused.

## Features

- **Studio:** Undo and redo step through the project history, whoever made the change ([36f8bd0e91](https://github.com/heygen-com/hyperframes/commit/36f8bd0e9112f4af7a09941b3f0f52864d5bd501), [#4456](https://github.com/heygen-com/hyperframes/pull/4456)).
