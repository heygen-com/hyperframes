# HyperFrames v0.8.53

Released on 2026-09-20.

Every Studio panel now lives on the dockable layout, and the arrangement is remembered between sessions. Host apps can import the header logo, button sizes and a stable stylesheet. Studio also stops reporting cancelled thumbnail loads as errors, which had been burying real problems in telemetry.

## Features

- **Studio:** Export the header logo, button sizes and a stable styles.css subpath ([2d84937e1](https://github.com/heygen-com/hyperframes/commit/2d84937e1f28ee60dd7dc23bdedfd324793e10d0), [#4197](https://github.com/heygen-com/hyperframes/pull/4197)).
- **Studio:** All panels move onto the dockable, persisted layout ([98e8372a0](https://github.com/heygen-com/hyperframes/commit/98e8372a0aaaefd498a558db96ed2d2feac3a275), [#4192](https://github.com/heygen-com/hyperframes/pull/4192)).
