# HyperFrames v0.8.193

Released on 2026-10-24.

Cloud renders of long, cut-heavy edits finish several times faster at the same or lower cost. Audio renders work again on FFmpeg 4.4.

## Fixes

- **Engine:** Audio encodes on FFmpeg 4.4, which has no setts duration option ([3d45d1b037860](https://github.com/heygen-com/hyperframes/commit/3d45d1b037860afd42439a2b4ca7e0dc762448c3), [#6219](https://github.com/heygen-com/hyperframes/pull/6219)).
- **CLI:** Each start sweeps the running markers of CLIs that are gone ([24965372dbbec](https://github.com/heygen-com/hyperframes/commit/24965372dbbec90391978e223616c75045b9a813), [#5790](https://github.com/heygen-com/hyperframes/pull/5790)).
- **CLI:** Snapshot rejects a negative --at and builds its sheet from its own frames ([80be6ff039bb7](https://github.com/heygen-com/hyperframes/commit/80be6ff039bb7bb9c4ad2160441cf25fc29faf26), [#6179](https://github.com/heygen-com/hyperframes/pull/6179)).
- **CLI:** Snapshot seeks into a HEVC cut whose index lands a keyframe early ([3cbd98890e6f6](https://github.com/heygen-com/hyperframes/commit/3cbd98890e6f6f2c9544e753deedbd658486b569), [#6217](https://github.com/heygen-com/hyperframes/pull/6217)).
- **Studio Server:** A history restore refuses to remove every tracked file ([0eae4946d33f3](https://github.com/heygen-com/hyperframes/commit/0eae4946d33f3d874478fa7a292f3aae6a669ce1), [#6175](https://github.com/heygen-com/hyperframes/pull/6175)).
- **Engine:** Disable Dawn's DXC on Windows so WebGPU requestDevice succeeds ([3dc0b97bfdfe3](https://github.com/heygen-com/hyperframes/commit/3dc0b97bfdfe33cfb44c3655bd2849a4981e3842), [#5830](https://github.com/heygen-com/hyperframes/pull/5830)).
- **Studio:** A scene swap no longer keeps the previous preview window in memory ([291144e87ddfe](https://github.com/heygen-com/hyperframes/commit/291144e87ddfee93a3cd01764810311f0b5c5016), [#6207](https://github.com/heygen-com/hyperframes/pull/6207)).
- **Core:** Color grading builds a new WebGL context when a lost one is never restored ([700187b855de3](https://github.com/heygen-com/hyperframes/commit/700187b855de3cd35d9094e5006407dddd41a2ce), [#6211](https://github.com/heygen-com/hyperframes/pull/6211)).
- **Producer:** A render's page-error count includes what the capture workers saw ([1ab871fb117aa](https://github.com/heygen-com/hyperframes/commit/1ab871fb117aa4a5172c9d28c4c3d4556cedebbc), [#6196](https://github.com/heygen-com/hyperframes/pull/6196)).
- **Engine:** Renames ride out Windows file locks instead of failing the render ([0a8a78edec413](https://github.com/heygen-com/hyperframes/commit/0a8a78edec413f04b127ac2454f071793bd83000), [#6210](https://github.com/heygen-com/hyperframes/pull/6210)).
