# HyperFrames v0.8.114

Released on 2026-10-02.

Renaming a file in Studio now rewrites only the references that point at it, and keyframe edits no longer copy other animations' values. Manual edits also stay under 8 ms per frame, and Studio reads modern CSS colors.

## Fixes

- **Studio Server:** A rename rewrites only references that name the renamed path ([1168bb740d33](https://github.com/heygen-com/hyperframes/commit/1168bb740d336f366849c91308a3c2bbb850c570), [#4915](https://github.com/heygen-com/hyperframes/pull/4915)).
- **Studio:** Parse modern CSS colors without a new dependency ([5c52f72399e2](https://github.com/heygen-com/hyperframes/commit/5c52f72399e21f8dcf3ede2bf2d24978c6522a94), [#3931](https://github.com/heygen-com/hyperframes/pull/3931)).
- **Studio:** Keep a keyframe edit from copying other tweens' channels ([dc9c38efd8f6](https://github.com/heygen-com/hyperframes/commit/dc9c38efd8f6eadefb654d73f55e6e8671a1c8f4), [#4918](https://github.com/heygen-com/hyperframes/pull/4918)).
