# HyperFrames v0.8.168

Released on 2026-10-17.

Scrubbing back across a scene in the preview now shows its content instead of an empty frame. Cloud renders size their chunks to the worker limit and assemble in one pass, so long videos finish faster.

## Features

- **Producer:** Distributed renders accept 25 fps ([cc9e1bb33a4](https://github.com/heygen-com/hyperframes/commit/cc9e1bb33a430b878af6dcb257ce5c9a70f9f180), [#5423](https://github.com/heygen-com/hyperframes/pull/5423)).
- **Producer:** Render at 720p and 480p from a larger composition ([09c0307c3fd](https://github.com/heygen-com/hyperframes/commit/09c0307c3fd0318a7ea77e6b41df4e5d30a1902b), [#5724](https://github.com/heygen-com/hyperframes/pull/5724)).
