# HyperFrames v0.8.210

Released on 2026-10-27.

MOV renders can now pick a ProRes profile, and HDR sources render correctly to formats that cannot carry HDR. A page whose renderer crashes now fails at once with a clear reason instead of hanging.

## Features

- **CLI:** Render --prores-profile picks ProRes 4444, hq, 422, lt or proxy for MOV ([957df5c268c66](https://github.com/heygen-com/hyperframes/commit/957df5c268c6622c94879a701c845d35d72d1762), [#6581](https://github.com/heygen-com/hyperframes/pull/6581)).
- **CLI:** Doctor names the tested ffmpeg build and says loudness is only comparable on it ([98e774384efdc](https://github.com/heygen-com/hyperframes/commit/98e774384efdc785c7d49947948e796a8b8b4004), [#6566](https://github.com/heygen-com/hyperframes/pull/6566)).
