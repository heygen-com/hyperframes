# HyperFrames v0.9.7

Released on 2026-11-03.

Studio playback no longer freezes WebGL scenes when motion blur is on. Preview playback now lands on the same frame as a scrub or an export when a set cuts into a running tween. Your CLI login now takes priority over an API key left in your shell.

## Features

- **Lint:** `overlapping_gsap_tweens` now also flags a `set` that fires while a tween on the same element and property is still running, a pattern that plays differently from how it scrubs and exports ([5e30bbdbe](https://github.com/heygen-com/hyperframes/commit/5e30bbdbe14b8295f8102c6439aa8bfdacc0fd1e), [#7059](https://github.com/heygen-com/hyperframes/pull/7059)).
- **Preview:** A video the browser cannot play, such as HEVC without a decoder or ProRes, shows its own frame at the playhead instead of black while its playable copy is made. Copy progress is now reported at Full quality too ([eb3562966](https://github.com/heygen-com/hyperframes/commit/eb3562966fcbac74da75566b660cbb41aa940739), [#6589](https://github.com/heygen-com/hyperframes/pull/6589)).

## Fixes

- **Studio:** With motion blur on, a scene that draws to a WebGL canvas no longer freezes during preview playback. Motion blur now falls back for those scenes, as it already did in renders ([112ba5330](https://github.com/heygen-com/hyperframes/commit/112ba53302726f2135dc7b28b03033b5a897ffbd), [#7060](https://github.com/heygen-com/hyperframes/pull/7060)).
- **Core:** Preview playback now lands on the same frame as a scrub or an export when a `set` fires inside a running tween on the same property. Before, a word hidden just before its pop-in ended could stay on screen while playing ([0f85af7c7](https://github.com/heygen-com/hyperframes/commit/0f85af7c7fd90ab755cd6f5c7f879eef7ed2aacc), [#7061](https://github.com/heygen-com/hyperframes/pull/7061)).
- **CLI:** `hyperframes cloud render` no longer offers `--page-motion-blur`, because the hosted render API rejected requests that used it. Turn motion blur on in the composition with `data-motion-blur="on"`. Local `hyperframes render --page-motion-blur` is unchanged ([dffc640e8](https://github.com/heygen-com/hyperframes/commit/dffc640e8556b675e7e1d73f482c19ee7e855782), [#7062](https://github.com/heygen-com/hyperframes/pull/7062)).
- **CLI:** A session from `hyperframes auth login` now takes priority over `HEYGEN_API_KEY` and `HYPERFRAMES_API_KEY`, so a key left in your shell no longer replaces the account you signed in with. The key still wins when `HEYGEN_API_URL` or `HEYGEN_API_BASE` points at another host, or when the login cannot refresh ([d03bdeae9](https://github.com/heygen-com/hyperframes/commit/d03bdeae9d992c9bb653bb1e67cf5569d16455f3), [#7051](https://github.com/heygen-com/hyperframes/pull/7051)).
- **Studio Server:** Two exports of the same project started within one second now get their own jobs and output files. Before, the second export replaced the first ([92943d99f](https://github.com/heygen-com/hyperframes/commit/92943d99f08394b4a9d3964471ccae1bb86c83de), [#7053](https://github.com/heygen-com/hyperframes/pull/7053)).
- **CLI:** `hyperframes snapshot` no longer crashes Chrome on a project with many clips cut from one 4K video. Like render, it now stops Chrome from decoding local videos it already replaces with extracted frames ([81b93cf05](https://github.com/heygen-com/hyperframes/commit/81b93cf055dee34ec1e47e1e64e0c5bba35aef05), [#6949](https://github.com/heygen-com/hyperframes/pull/6949)).
- **CLI:** The `latestVersion` value in `--json` output is never older than the CLI you are running, even right after an upgrade ([8a6636efe](https://github.com/heygen-com/hyperframes/commit/8a6636efe36c3ec313aeb4a122f875b687ffdc5d), [#7049](https://github.com/heygen-com/hyperframes/pull/7049)).
- **CLI:** `hyperframes auth login --device` now works without a terminal, such as in a coding agent's shell or an SSH command. It still refuses to run in CI ([de2603e63](https://github.com/heygen-com/hyperframes/commit/de2603e637f09fc0490d06bf92151dddc8d0650f), [#7045](https://github.com/heygen-com/hyperframes/pull/7045)).
