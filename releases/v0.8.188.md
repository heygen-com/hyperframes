# HyperFrames v0.8.188

Released on 2026-10-23.

Lambda cloud renders now run their video work on arm64 by default, which costs less per render. Pass --video-arch x86_64 to keep x86.

This release also fixes renders in folders with a percent sign, long renders with small frames, scripts that shadow console, and motion blur, audio timing and frame handling.

## Features

- **CLI:** Lambda deploy renders on arm64 by default, and --video-arch x86_64 keeps x86 ([504ec2b30](https://github.com/heygen-com/hyperframes/commit/504ec2b307625f790a633184355c07aa3381b8f6), [#6073](https://github.com/heygen-com/hyperframes/pull/6073)).
