# HyperFrames v0.8.135

Released on 2026-10-05.

Studio edits preserve animation easing and Undo restores the latest edit, while Layers icons and nested scenes behave more predictably. Catalog previews now load under the docs site's script policy, with safer script encoding.

- **Studio:** Keyframed animations keep their ease through every Studio edit ([0d5e395cd3](https://github.com/heygen-com/hyperframes/commit/0d5e395cd31d0f491e9b26d0da110da6e231c512), [#5051](https://github.com/heygen-com/hyperframes/pull/5051)).
- **Studio:** Undo takes back the last edit, even right after a resize or a nudge ([98fe011699](https://github.com/heygen-com/hyperframes/commit/98fe011699999901affa2f6aa558568d17dc9e1a), [#5048](https://github.com/heygen-com/hyperframes/pull/5048)).
- **Studio:** Layers rows show a kind icon, and only a group row has a caret ([f7d6734761](https://github.com/heygen-com/hyperframes/commit/f7d6734761967860eaecd7466ba610ef9bef349b), [#5067](https://github.com/heygen-com/hyperframes/pull/5067)).
