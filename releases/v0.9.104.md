# HyperFrames v0.9.104

Released on 2026-11-27.

A sealed canvas drag keeps its drop again, sealed previews load as fast as open ones, and Studio's server stops blocking on waveform reads. Timeline clips load media only from their own project, and a busy preview reload retries after the server's wait.

## Features

- **Core:** A frame-presented wait can be asked to run longer, up to 15 s ([4c92e37a7](https://github.com/heygen-com/hyperframes/commit/4c92e37a708662240c1a96d53d0565332a1aea8d), [#8976](https://github.com/heygen-com/hyperframes/pull/8976)).
- **Parsers:** Export the size the renderer compiles a composition at ([a7cca1a2e](https://github.com/heygen-com/hyperframes/commit/a7cca1a2e47e7275de366623508e1cb075fa717f), [#8974](https://github.com/heygen-com/hyperframes/pull/8974)).
