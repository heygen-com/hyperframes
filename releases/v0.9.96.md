# HyperFrames v0.9.96

Released on 2026-11-25.

A sealed player plays its film's audio in Safari, and a drag right after a reload moves the element on screen. A page can no longer grow a render's script record or log without end, and lint reports a file it cannot parse instead of failing the run.

## Features

- **Player:** A sealed player plays its film's audio from decoded buffers in Safari ([dd4f20d1b5](https://github.com/heygen-com/hyperframes/commit/dd4f20d1b5dc615bef9825ff9ac73041d7fd6f63), [#8636](https://github.com/heygen-com/hyperframes/pull/8636)).

## Fixes

- **Lint:** Report a file the HTML parser refuses as a finding instead of failing the run ([9f1b1b437c](https://github.com/heygen-com/hyperframes/commit/9f1b1b437c650b79e65ea2583b77c2b933baa6e4), [#8853](https://github.com/heygen-com/hyperframes/pull/8853)).
- **Studio:** A drag pressed right after a reload moves the element on screen ([1aaf2a2859](https://github.com/heygen-com/hyperframes/commit/1aaf2a2859d7d5c1df21d99f7ec48fbc596bcdc2), [#8836](https://github.com/heygen-com/hyperframes/pull/8836)).
- **Media Use:** Wait-bgm looks for the track before it reports a timeout ([f78ba24e75](https://github.com/heygen-com/hyperframes/commit/f78ba24e75f0eef37e9a79fc1a4bb35c8533a68f), [#8856](https://github.com/heygen-com/hyperframes/pull/8856)).
- **Engine,producer:** A page cannot grow a render's script record or its log without end ([6e6e7e013d](https://github.com/heygen-com/hyperframes/commit/6e6e7e013db75bf9c2cda5de439f7baaea461827), [#8854](https://github.com/heygen-com/hyperframes/pull/8854)).
