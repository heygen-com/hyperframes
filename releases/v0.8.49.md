# HyperFrames v0.8.49

Released on 2026-09-18.

Films embedded from another origin now wait for their images and media before the first frame plays, and dropping a clip onto an empty main track starts it at 0. The rest is render-ready and catalog fixes.

## Features

- **Studio:** The first clip on an empty main track now starts at 0 ([707f9a44c](https://github.com/heygen-com/hyperframes/commit/707f9a44c352cead071f2ca6e67ee61ef676c484), [#4099](https://github.com/heygen-com/hyperframes/pull/4099)).
- **Studio:** The editor now reports the real reason an edit was declined, one of four causes, instead of one generic one ([61db45313](https://github.com/heygen-com/hyperframes/commit/61db4531337f6586cff80c130fb459e8d0bc6360)).

## Fixes

- **Player:** A composition embedded from another origin waits for its assets before playing, so viewers no longer see a half-loaded first frame ([a7282dcd0](https://github.com/heygen-com/hyperframes/commit/a7282dcd0eb888ab496dcbd41a1e35ac2a3bb1c7), [#4103](https://github.com/heygen-com/hyperframes/pull/4103)).
- **Producer:** Renders look up Google Fonts CSS once per process instead of on every use ([a7ec66b12](https://github.com/heygen-com/hyperframes/commit/a7ec66b1248ddf704656676717005bdfd2aee946), [#4097](https://github.com/heygen-com/hyperframes/pull/4097)).
- **Core:** A media file that already failed to load no longer holds the readiness gate for the full 8 second timeout ([15460ec54](https://github.com/heygen-com/hyperframes/commit/15460ec541a89d35e9080b78c2c54a3b288c1735), [#4096](https://github.com/heygen-com/hyperframes/pull/4096)).
- **Studio:** Selecting several clips checks their network probes in parallel, so the preview syncs faster ([cc36905c2](https://github.com/heygen-com/hyperframes/commit/cc36905c29851545f95feabc86f62722b673807c), [#4088](https://github.com/heygen-com/hyperframes/pull/4088)).
- **Studio:** After you drop a clip on the timeline it is selected and scrolled into view ([42f947f4c](https://github.com/heygen-com/hyperframes/commit/42f947f4c3360c55a28546b9abc93624615eb0a1), [#4067](https://github.com/heygen-com/hyperframes/pull/4067)).
- **Core:** Selector arrays like querySelectorAll results stay inside their own composition ([27303658c](https://github.com/heygen-com/hyperframes/commit/27303658c1dc230cd16acdfbcb45606a7eb42a95), [#4035](https://github.com/heygen-com/hyperframes/pull/4035)).
- **Core:** Renders wait for a composition's declared compute to finish, not only for adapter loaders ([e36a53d6b](https://github.com/heygen-com/hyperframes/commit/e36a53d6b6bd0a5d3da13c0f2f18fc9af255e747), [#4065](https://github.com/heygen-com/hyperframes/pull/4065)).

## Catalog

- **Catalog:** The catalog is now a live grid you browse, not a static index ([9bb4f5cd5](https://github.com/heygen-com/hyperframes/commit/9bb4f5cd571dcf2910078a99efcb65a5d616f917), [#4051](https://github.com/heygen-com/hyperframes/pull/4051)).
- **Catalog:** Catalog items fall back to a recorded video when their directory is over the size budget ([a0e7c4392](https://github.com/heygen-com/hyperframes/commit/a0e7c43921e138a891bc604c8b109230143608f1), [#4084](https://github.com/heygen-com/hyperframes/pull/4084)).
- **Registry:** The 12 VS Code theme blocks have their own root id and the right asset path ([d6a0c407d](https://github.com/heygen-com/hyperframes/commit/d6a0c407d7ab41ae171b85f4bd97b79cbf4b1f3e), [#4094](https://github.com/heygen-com/hyperframes/pull/4094)).
- **Registry:** Four blocks that build their timeline asynchronously register it only once it exists ([227933399](https://github.com/heygen-com/hyperframes/commit/22793339900986e153c22747d4c148a8a500f0fd), [#4086](https://github.com/heygen-com/hyperframes/pull/4086)).
- **Registry:** The iPhone device block no longer waits on requestAnimationFrame to show its screens ([81ca5f418](https://github.com/heygen-com/hyperframes/commit/81ca5f41878559d1d2604514409c23caa5d0a11c), [#4083](https://github.com/heygen-com/hyperframes/pull/4083)).
