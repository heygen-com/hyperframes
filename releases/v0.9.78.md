# HyperFrames v0.9.78

Released on 2026-11-21.

A catalog gap report on Windows never puts a query your shell would run into a command. Renders sharing one capture proxy no longer lose connections, and more CLI messages show control characters as plain text.

## Features

- **Engine:** A late image's load time is logged when it arrives ([e65b11e5c](https://github.com/heygen-com/hyperframes/commit/e65b11e5c2be2c73d3ab0ea5628c51ec13f68a21), [#8372](https://github.com/heygen-com/hyperframes/pull/8372)).
