# HyperFrames v0.9.78

Released on 2026-11-21.

Renders that share one capture proxy across many browsers no longer lose connections. Opening a preview file no longer stalls on a slow drive, and more CLI messages show control characters as plain text.

## Fixes

- **Engine:** A capture proxy shared by many browsers no longer drops tunnels at 128 ([5e16c18b1](https://github.com/heygen-com/hyperframes/commit/5e16c18b1d239f7e1225f59be5c44614a6d9d784), [#8362](https://github.com/heygen-com/hyperframes/pull/8362)).
- **CLI:** Show control characters as text in init, skills and render printed lines ([8bc73a0bd](https://github.com/heygen-com/hyperframes/commit/8bc73a0bd34313790bdbf6be43cf67f311800711), [#8352](https://github.com/heygen-com/hyperframes/pull/8352)).
- **CLI:** Show control characters as text in more commands' printed lines ([7a1163fc9](https://github.com/heygen-com/hyperframes/commit/7a1163fc98149719c636a170aad6c99e2d68a291), [#8353](https://github.com/heygen-com/hyperframes/pull/8353)).
- **Studio Server:** A preview file request no longer waits on a silent drive on the event loop ([7cb605c78](https://github.com/heygen-com/hyperframes/commit/7cb605c787f4e85f66a2a46df60f8fdbe13faad6), [#8254](https://github.com/heygen-com/hyperframes/pull/8254)).

## Internal

- **Studio Server:** A held-file edit is checked for blocking waits, not wall-clock gaps ([29a5003ee](https://github.com/heygen-com/hyperframes/commit/29a5003eebdd1a1a01e4d1a4e3f375da93b078ab), [#8236](https://github.com/heygen-com/hyperframes/pull/8236)).
- **Studio Server:** A held save proves it never sleeps the thread, not a 100 ms stall bound ([ba81f6793](https://github.com/heygen-com/hyperframes/commit/ba81f67930cce689b1444c03dc3a4c0dbf13e97b), [#8359](https://github.com/heygen-com/hyperframes/pull/8359)).
