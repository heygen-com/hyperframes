# HyperFrames v0.8.82

Released on 2026-09-28.

Renders now match the preview more closely in video frames, fonts and shader transitions. Studio plays back and seeks faster, and the CLI can transcribe with Parakeet after an opt-in install.

## Features

- **Core:** Export findProjects to list the HyperFrames projects on a machine ([e738e10267](https://github.com/heygen-com/hyperframes/commit/e738e1026793d144e95803a3a575fe448c07d90f), [#4627](https://github.com/heygen-com/hyperframes/pull/4627)).
- **CLI:** Tag telemetry and feedback with the app that launched the CLI ([fa044a89e5](https://github.com/heygen-com/hyperframes/commit/fa044a89e56239225daef39e4904bde2d9442ed5), [#4632](https://github.com/heygen-com/hyperframes/pull/4632)).
- **Studio:** Let a host app mount the timeline toolbar, undo buttons, meters and clipboard ([bc73c411f0](https://github.com/heygen-com/hyperframes/commit/bc73c411f0bbf2b5e79c362ec78300ff5f08c520), [#4629](https://github.com/heygen-com/hyperframes/pull/4629)).
- **CLI:** Transcribe with Parakeet on macOS, Linux and Windows after an opt-in install ([5cbef29d3a](https://github.com/heygen-com/hyperframes/commit/5cbef29d3add1b40d08bcdf2c1ffcf758b8b7f5d), [#4583](https://github.com/heygen-com/hyperframes/pull/4583)).
