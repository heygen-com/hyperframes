# HyperFrames v0.9.32

Released on 2026-11-11.

Long films that are slow to open now render instead of failing before their first frame. The CLI, Studio and the renderer also stop a project folder from choosing what they run or serve.

## Features

- SDR MP4 renders can keep full colour detail with `--chroma-subsampling 444`, for masters that will be re-encoded; the default is unchanged ([1a9fb8acb](https://github.com/heygen-com/hyperframes/commit/1a9fb8acb65d044e1732381fad953b69c3604648), [#5820](https://github.com/heygen-com/hyperframes/pull/5820)).
- **Producer:** The render stream's complete event names the producer version that rendered it ([7afa05a78](https://github.com/heygen-com/hyperframes/commit/7afa05a782c452ca76af22bdde12d4cddaf64c60), [#7515](https://github.com/heygen-com/hyperframes/pull/7515)).

## Fixes

- **Share:** Guide recovery when an export replay is refused ([941049a84](https://github.com/heygen-com/hyperframes/commit/941049a84470caf3358962577e4c1faeecdfc95d), [#7531](https://github.com/heygen-com/hyperframes/pull/7531)).
- **Studio:** The composition hover preview runs walled off from Studio's own page, so a composition's scripts cannot reach into Studio ([0c229a26c](https://github.com/heygen-com/hyperframes/commit/0c229a26c9e1ad91a3b1df3b24100be6f10ae3db), [#7522](https://github.com/heygen-com/hyperframes/pull/7522)).
- **Studio:** Pressing Enter or Escape while an input method is still composing text no longer commits it, and Escape then leaving a text field no longer saves the cancelled edit ([ff285d3f2](https://github.com/heygen-com/hyperframes/commit/ff285d3f2b3a2199e8068f02c192140ed72d2015), [#6011](https://github.com/heygen-com/hyperframes/pull/6011)).
- **Share:** A share or export killed while taking its lock no longer leaves a lock that later attempts cannot clear, on file systems without hard links ([b37e4b026](https://github.com/heygen-com/hyperframes/commit/b37e4b026f0cd725ed7588d6648263d5cda1e046), [#7516](https://github.com/heygen-com/hyperframes/pull/7516)).
- **Producer:** Long films that are slow to open no longer fail before their first frame: the wait for the first frame now follows how long the browser took to start, up to 15 minutes ([7ff8ece46](https://github.com/heygen-com/hyperframes/commit/7ff8ece461e87282e17f3da14f0b83d0cbe9d38f), [#7517](https://github.com/heygen-com/hyperframes/pull/7517)).
- **Lint:** Flag a script that calls gsap before GSAP loads, and say so when a render fails on it ([124591a9d](https://github.com/heygen-com/hyperframes/commit/124591a9d5d54fb90ab9ab832ced2b3af1527d11), [#7514](https://github.com/heygen-com/hyperframes/pull/7514)).
- **Producer,engine:** Harden render paths, render slots and local listeners ([60fb9d2c5](https://github.com/heygen-com/hyperframes/commit/60fb9d2c5e0c213787888300dd98b8cb05fc2b31), [#7508](https://github.com/heygen-com/hyperframes/pull/7508)).
- **Studio Server:** Harden preview paths, cache folders and local servers ([b8bb49190](https://github.com/heygen-com/hyperframes/commit/b8bb4919003fd5082a0db481271db4baf7701b30), [#7510](https://github.com/heygen-com/hyperframes/pull/7510)).
