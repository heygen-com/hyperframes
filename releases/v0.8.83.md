# HyperFrames v0.8.83

Released on 2026-09-28.

Host apps can reuse more of Studio, including DOM editing, snapping, marquee selection and paint order in step with timeline rows. HDR footage looks the same in preview and render, and a CLI update no longer lands under a running command.

## Features

- **Studio:** A host app can reuse Studio's DOM editing outside the Studio editor ([2251e5fad](https://github.com/heygen-com/hyperframes/commit/2251e5fad01f841700098b91811c06f10d37f430), [#4640](https://github.com/heygen-com/hyperframes/pull/4640)).
- **Studio:** Let a host app keep paint order in step with timeline rows ([93ab2899f](https://github.com/heygen-com/hyperframes/commit/93ab2899f13a1120002986793a7b11b657841b69), [#4647](https://github.com/heygen-com/hyperframes/pull/4647)).
- **Studio:** A host app can reuse Studio's snapping and marquee selection in its own preview ([4aa6b168f](https://github.com/heygen-com/hyperframes/commit/4aa6b168fea84a3a1a129e20d42974427b77615e), [#4635](https://github.com/heygen-com/hyperframes/pull/4635)).
- **Studio Server:** List the projects the history cache knows, with their folders ([00ac4ef57](https://github.com/heygen-com/hyperframes/commit/00ac4ef571c6ccf7cd90cb65b23efaa7f74ea1f9), [#4639](https://github.com/heygen-com/hyperframes/pull/4639)).
