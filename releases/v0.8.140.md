# HyperFrames v0.8.140

Released on 2026-10-07.

Renders now report encoding and assembly progress, and motion blur works over video. Automatic workers respect memory limits, while composition checks avoid false motion and text-overlap alarms.

- **Core:** Bound imported scene timing to source intervals ([f74f26028](https://github.com/heygen-com/hyperframes/commit/f74f26028616eea9baa99b4610d0960688436f27), [#5132](https://github.com/heygen-com/hyperframes/pull/5132)).
