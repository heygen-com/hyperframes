# HyperFrames v0.9.34

Released on 2026-11-11.

HyperFrames now runs helper programs like FFmpeg only from where they are installed, never from a project folder. Renders can also refuse variables a page does not declare, when that check is turned on.

## Features

- **Producer:** With strict variables turned on, a render fails when it is given a variable the page does not declare. It is off by default, so renders are unchanged ([f312fca7e](https://github.com/heygen-com/hyperframes/commit/f312fca7e2098524af07055bdf6c20a3706d6f89), [#7548](https://github.com/heygen-com/hyperframes/pull/7548)).

## Fixes

- **Studio Server:** Load fonts and modules only in the Studio's own preview frames ([ffb13c3b6](https://github.com/heygen-com/hyperframes/commit/ffb13c3b62a1b8ed98fdcd835f15412d0a7ca7e6), [#7553](https://github.com/heygen-com/hyperframes/pull/7553)).
- **Skills:** Plugin launcher and media helpers run the pinned CLI, not a project copy ([a8fe3a5b6](https://github.com/heygen-com/hyperframes/commit/a8fe3a5b6844c9f1ae1a4473793eeb11dfcec627), [#7552](https://github.com/heygen-com/hyperframes/pull/7552)).
- **CLI:** Preview uses the bundled Studio unless local Studio mode is opted in ([668983e1a](https://github.com/heygen-com/hyperframes/commit/668983e1a63efb7618049c73cf9dcad2a5977a4e), [#7551](https://github.com/heygen-com/hyperframes/pull/7551)).
- **Security:** FFmpeg, FFprobe and other helper programs are taken only from where they are installed or a path you set, never from a project folder ([84799bdc5](https://github.com/heygen-com/hyperframes/commit/84799bdc59b18f6a3df6595d8a8d1ec03dfde673), [#7524](https://github.com/heygen-com/hyperframes/pull/7524)).
- **Core:** Saving a file works on drives that refuse hard links with a permission error ([f36463e29](https://github.com/heygen-com/hyperframes/commit/f36463e292f4487daef522ec9b19c2dacceb6adb), [#7474](https://github.com/heygen-com/hyperframes/pull/7474)).
- **Studio:** Thumbnails are captured in a sealed page, and shader transitions still work where the browser blocks local storage ([80cda85d7](https://github.com/heygen-com/hyperframes/commit/80cda85d761128e121a1cef0f1378ad342472411), [#7528](https://github.com/heygen-com/hyperframes/pull/7528)).
