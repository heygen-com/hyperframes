# HyperFrames v0.8.185

Released on 2026-10-21.

`hyperframes cloud render --resolution 4k` now works for transparent MOV and WebM. A render no longer fails when its audio peak stalls under correction, `check` accepts projects that inline the GSAP library, and cloud render chunks start their capture browsers while video frames extract. Capture motion blur arrives as an opt-in on the composition root.

## Features

- **CLI:** `cloud render --resolution 4k` accepts `--format mov` and `--format webm`; the CLI and the render server no longer refuse 4K with a transparent format ([25126bca6](https://github.com/heygen-com/hyperframes/commit/25126bca6ced6cb8c839213430cde51e48261b7c), [#6045](https://github.com/heygen-com/hyperframes/pull/6045)).
- **Core:** Capture motion blur: `data-motion-blur` on the composition root blurs fast-moving elements across sub-frame samples, with shutter angle and sample count settings ([0f1d6908f](https://github.com/heygen-com/hyperframes/commit/0f1d6908fdfb4dc7b9ac21520b7e9e268c87aacc), [#5967](https://github.com/heygen-com/hyperframes/pull/5967)); it follows the render's device scale, so 2x and 4K renders blur at full resolution ([ffcef8f88](https://github.com/heygen-com/hyperframes/commit/ffcef8f886b4a1ed9dba12f21b9939db5c17746e), [#5968](https://github.com/heygen-com/hyperframes/pull/5968)).

## Fixes

- **Producer:** A render whose AAC true peak stalls above the limit during correction no longer fails at assemble ([32ebdde61](https://github.com/heygen-com/hyperframes/commit/32ebdde61266c0858a193855436be5c703a6171a), [#6043](https://github.com/heygen-com/hyperframes/pull/6043)).
- **Lint:** `check` no longer fails a project that pastes the GSAP library inline, and a bundle around GSAP never inherits its exemption ([50e7e8df6](https://github.com/heygen-com/hyperframes/commit/50e7e8df69e8e29eb897ef25f310de92949e6062), [#6018](https://github.com/heygen-com/hyperframes/pull/6018)).
- **Engine:** A capture browser whose BeginFrame probe passed keeps BeginFrame capture when closing the probe page is slow ([a8b576d15](https://github.com/heygen-com/hyperframes/commit/a8b576d156109a3fdd519cb7b14aead6cfd2118e), [#6037](https://github.com/heygen-com/hyperframes/pull/6037)).

## Performance

- **Producer:** A cloud render chunk starts its capture browsers while its video frames are still being extracted, so heavy chunks finish sooner and cost less ([0716670fa](https://github.com/heygen-com/hyperframes/commit/0716670faf6803d9b8a0c3d2d92e62f45759ee07), [#6031](https://github.com/heygen-com/hyperframes/pull/6031)).
