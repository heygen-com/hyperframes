# HyperFrames v0.8.67

Released on 2026-09-23.

Lint findings now include one-based source line and column locations when they can be identified unambiguously. CLI output shows `file:line:column`, and JSON includes `line` and `column`.

## Changes

- Add source locations to lint findings ([#4353](https://github.com/heygen-com/hyperframes/pull/4353)).
- Keep live reload working after atomic saves on Linux ([#4346](https://github.com/heygen-com/hyperframes/pull/4346)).
- Update Studio panel tabs ([#4266](https://github.com/heygen-com/hyperframes/pull/4266)).
- Scope catalog dispatch and fail closed on detection errors ([#4347](https://github.com/heygen-com/hyperframes/pull/4347)).
