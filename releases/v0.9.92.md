# HyperFrames v0.9.92

Released on 2026-11-24.

A hand move in a sealed Studio preview now saves the same CSS as unsealed, and a sealed player follows redirects cleanly. Renders no longer stop on an image URL Node cannot parse, and local media, LUT paths and pasted edits stay where they belong.
