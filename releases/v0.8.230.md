# HyperFrames v0.8.230

Released on 2026-11-01.

Apps that host Studio can now remap its single-key shortcuts. Media sources given as file: URLs or Git Bash paths now resolve. Cache folders follow HYPERFRAMES_CACHE_DIR, and a preview reload that timed out is tried once more.

## Features

- **Studio:** Hosts can remap Studio's single-key shortcuts ([57d23598a](https://github.com/heygen-com/hyperframes/commit/57d23598a7269ac7e4d9c01003eb8c6039ed198b), [#6957](https://github.com/heygen-com/hyperframes/pull/6957)).
