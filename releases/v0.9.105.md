# HyperFrames v0.9.105

Released on 2026-11-28.

Sealed previews now edit like open ones: drags, resizes and crops move with the layer and save the same box. Studio and the preview runtime share a new editing channel. Update both to 0.9.105 together, or a sealed preview cannot be edited.

## Features

- **Core:** Paint a sealed preview's drag chrome in the same frame as the layer ([11ac2d6d3](https://github.com/heygen-com/hyperframes/commit/11ac2d6d37efa43d4b9a0fb54456cfceab26858e), [#8961](https://github.com/heygen-com/hyperframes/pull/8961)).
- **Studio:** Prototype sealed canvas keys acted on only right after a real click or key ([b0ee64ab7](https://github.com/heygen-com/hyperframes/commit/b0ee64ab72e5bda5867752eb22efbc3e0c839e05), [#8992](https://github.com/heygen-com/hyperframes/pull/8992)).
