# HyperFrames v0.8.198

Released on 2026-10-25.

Cloud renders now split the work by how costly each part is to capture, so one heavy stretch no longer holds up the rest. On a heavy 4K test project that made renders about a third faster at the same cost. Snapshot also waits for slow scenes, and renders hide statically hidden elements the way preview does.

## Fixes

- **CLI:** Snapshot waits for a slow scene to finish building instead of saving a stale frame ([6b424e02c4987](https://github.com/heygen-com/hyperframes/commit/6b424e02c498746d922a7cbda6e63f206c55c9d4), [#6290](https://github.com/heygen-com/hyperframes/pull/6290)).
- **Core:** Hide static data-hidden elements in render as preview does ([36b2c3c2b9a48](https://github.com/heygen-com/hyperframes/commit/36b2c3c2b9a48b2205b5a9407761abf394e64ee5), [#6296](https://github.com/heygen-com/hyperframes/pull/6296)).
