# HyperFrames v0.9.14

Released on 2026-11-04.

Cloud renders no longer fail on common font styles, and they now carry the system fonts a project uses. A wedged render stops itself, and `check` no longer hangs on long videos.

## Features

- **CLI:** Cloud render carries the system fonts a project uses in its zip ([cba66f20a69c9](https://github.com/heygen-com/hyperframes/commit/cba66f20a69c9e929564a756852dac71c4c437de), [#7165](https://github.com/heygen-com/hyperframes/pull/7165)).
