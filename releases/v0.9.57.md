# HyperFrames v0.9.57

Released on 2026-11-16.

Studio exports a sealed preview's checked element reads and stand-ins, so a host app can build on them, and keeps recovery drafts with each project's own server. Media Use's audio engine and CLI batch outputs stay inside the project or working folder.
