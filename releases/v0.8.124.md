# HyperFrames v0.8.124

Released on 2026-10-04.

Undo in Studio now takes added media back with the file, snapping no longer moves a clip to a place it would not save, and motion paths animate when GSAP loads deferred. Media-use can clone, list and delete HeyGen voices.

## Features

- **Studio:** Make edit with framey stand out in the header ([2b82e39cd6fd](https://github.com/heygen-com/hyperframes/commit/2b82e39cd6fde19a74ce4855d5bfc05ceb42b864), [#5019](https://github.com/heygen-com/hyperframes/pull/5019)).
- **Media Use:** Clone, list and delete HeyGen voices, and accept a host OAuth token ([2497402b270a](https://github.com/heygen-com/hyperframes/commit/2497402b270a4f613cf57abc1c29cbc260fb8c07), [#4992](https://github.com/heygen-com/hyperframes/pull/4992)).
- **Skills:** Open Studio before every final render ([69a2169bde0c](https://github.com/heygen-com/hyperframes/commit/69a2169bde0c134f42979e1911755084b1c29962), [#4952](https://github.com/heygen-com/hyperframes/pull/4952)).
- **Cli,studio:** Hand off on macOS now, and open the app on Windows and Linux ([6a27a34f21ef](https://github.com/heygen-com/hyperframes/commit/6a27a34f21ef178d3c5189ab8a4a9f6709c528da), [#4999](https://github.com/heygen-com/hyperframes/pull/4999)).
