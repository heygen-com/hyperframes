# HyperFrames v0.9.103

Released on 2026-11-27.

Sealed previews can now hold stage acts, show removed elements as ghosts, and run Delete and arrow nudges in the frame. Cloud renders find files with percent-escaped names, and Windows renders no longer stall on long paths or a hung taskkill.

- **Studio:** Let a host take presses in a sealed film during a text edit ([831e2ff12](https://github.com/heygen-com/hyperframes/commit/831e2ff1215a4e8aba571300743fdba82bcfd883), [#8968](https://github.com/heygen-com/hyperframes/pull/8968)).
- **Core:** Stand a removed element back as a ghost in a sealed preview ([ad49fd5b9](https://github.com/heygen-com/hyperframes/commit/ad49fd5b933299b0fb76ac80e895869bd41dd920), [#8956](https://github.com/heygen-com/hyperframes/pull/8956)).

- **Core:** Tell the host where a press lands during a sealed text edit ([8a6e87fbe](https://github.com/heygen-com/hyperframes/commit/8a6e87fbe86fa9289bb7c1bb9ec4595e2d72ab24), [#8957](https://github.com/heygen-com/hyperframes/pull/8957)).
- **Studio:** Handle canvas Delete and arrow-key nudge in opaque preview runtime ([0c6f11a56](https://github.com/heygen-com/hyperframes/commit/0c6f11a56857f44dca010fa9e5ec2bb68a963ea9), [#8935](https://github.com/heygen-com/hyperframes/pull/8935)).
